## 不改变二维冻结接口

- 原 software/common/s1 与冻结 ABI 头/文档保持不变。新输入继续使用 doa_frame_input_t，顺序01/02/03/12/13/23。
- doa_solver_3d.h/c 为新增模块；doa_dispatch.h/c 为新增应用适配层。默认 SS_DOA_PROFILE=0 调用原二维；设为1调用三维。所有编译单元应一致配置。原调用者仍可直接调用 doa_solve，不受影响。
- 原 ss_poll_solve 仍只调用二维；原求解器批未替换Keil入口；D1现已实现S2 acquire→新解算入口→finish并接入独立三维目标，保持一次消费、错误隔离、总预算与禁动作。必须统一全目标宏，不能仅在main定义宏。
- 三维输出为新结构，包含ux/uy/uz、方位/俯仰及各自valid、残差、范数、几何条件数等。旧结构的vertical_valid仍为0。新模块不产生舵机命令。
- 与原SPI兼容指线格式、六对特征和事务结构兼容；原完整冻结文档明确规定二维几何/算法，不能声称三维也满足其二维数值条款。实际接合前需A共同记录三维配置附录；本次不更改线ABI版本或复用保留位。

## 几何与符号

单位mm，原点为四面体几何中心；+X前、+Y左、+Z上，右手系。底面水平、mic3在顶端，mic0为底面前点。坐标对象是声孔，不是PCB边缘。

|通道|X|Y|Z|
|---|---:|---:|---:|
|mic0|23.094011|0|-8.164966|
|mic1|-11.547005|20|-8.164966|
|mic2|-11.547005|-20|-8.164966|
|mic3|0|0|24.494897|

底面到顶点高度32.659863 mm，六边均40 mm。若制作时以底面为Z=0，四个Z统一加8.164966，方向解算不变。方位 atan2(y,x)，俯仰 atan2(z,sqrt(x²+y²))；正上/下方的方位不确定，应置azimuth_valid=0，不把0°作为有效结果。

冻结跨谱Xa*conj(Xb)对应lag=t_a-t_b。因此样点时差模型为 tau_ab=(r_b-r_a)·u*Fs/c，u指向声源。通道错接无法单靠范数或残差可靠检出，必须做实际编号/脉冲核对。

## 为什么选择40 mm

48 kHz、343m/s下最大延迟5.597668样点，低于当前每对至少±6的搜索中心范围；±8的两对也覆盖。全六对几何矩阵B满足B^T B=3200 I mm²，理想等权几何条件数为1；这仅描述几何，不保证实际声学精度。

bin7..85的上端3984.375 Hz；40 mm在343m/s下半波长频率4287.5 Hz，作为间距选择参考，不等于证明宽带GCC无混叠/无反射。扩大边长提高时差灵敏度，但会侵入搜索范围和高频空间歧义；40 mm是当前接口下的折中，不是实测最优结论。初版固定48kHz配置；实测温度/声速、尺寸变化仍应检查每对最大时差。

薄支架留出声孔传播路径，避免厚板/外壳遮挡，核对MEMS实际声孔朝向和指向差异。建议制作时声孔位置误差目标≤0.5 mm，并记录实际坐标而非把标称值当实测。该误差目标不是验收门限。

## 算术及开发参数

沿用原S25/S6输入校验、RNE插值和margin公式；几何资格使用实际每对距离。3D以double累计并解3×3最小二乘，输出float向量及RNE Q8角度。F407不具备硬件双精度，本批只验证AC5可编译；上板耗时和栈必须实测，不能沿用二维685/729us。以后若优化float/定点，需要另作数值比较。

开发默认：至少4个有效对（保留冗余检查）、法方程无穷范数条件数≤100、残差RMS≤0.5样点、向量范数0.85～1.15、物理时差余量0.125样点。这些是显式可配置研究参数，尚无实录标定或正式准确率承诺。检查秩/条件数，不以有效对数量替代几何可解性；先检查范数，再计算角度，避免强制归一化掩盖零矢量/异常时差。

nominal配置coordinates_measured=0；只有实测后才能置1，此字段只记录来源，不自动表示系统验收或运动许可。BIST始终拒绝为DOA3D_LEGACY_BIST：旧BIST用于原二维/传输核对，不冒充三维向量。取消、源错误、资格不足、退化、残差/范数异常均清除方向角有效性，不残留上次角度。
