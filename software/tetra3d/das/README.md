## 数值与方向约定

四通道数据顺序必须为 **CH0、CH1、CH2、CH3**。坐标配置的 JSON 行顺序可调整，`channel` 才是物理通道号。
三维方向指向声源，沿用求解器的同一 XYZ 坐标系：方位角从 +X 向 +Y，俯仰从 XY 平面向 +Z。

设单位方向为 u，麦克风位置为 r_i，参考为 CH0：

```text
d_i = fs / c * dot(r_i - r_0, u)   （r 使用米，d 使用采样点）
d_i_q12 = round_to_nearest_even(d_i * 4096)
y[n] = (x_0[n-d_0] + x_1[n-d_1] + x_2[n-d_2] + x_3[n-d_3]) / 4
```

采样点之间做线性插值，整数结果使用最近偶数舍入。`ux/uy/uz` 是求解器未归一化的拟合向量：适配器检查有效性和 norm 一致性，再归一化。极点的 `azimuth_valid=0` 不阻断有效空间方向。

标称几何最大参考通道相对延时 **5.59766763848 点**，在当前 ±8 点能力内。几何需非共面；超出延时能力直接拒绝，不截断延时。DAS 检查不替代求解器的完整几何校验，也不证明坐标已实测。

这是远场平面波模型，不估计声源距离。线性插值具有频率响应误差；未实现频率无失真的理想分数延时、MVDR、回声消除、混响消除或声纹识别。同方向、相近方向或低频干扰不保证被分离。

## 输出可听音频

输入 `four_channels.npy` 为 `(4,N)` 整数数组，样本值在 `[-8388608,8388607]`，禁止浮点、归一化数值或未经转换的打包字节。四路须同采样率、同采样时刻；采集若有通道固定延迟，应先校正。

```sh
python software/tetra3d/das/das_3d.py --geometry software/tetra3d/core/tetra40-nominal.json --input four_channels.npy --output beam_up.wav --direction 0 0 1
```

输出单声道 24-bit WAV，不覆盖已有文件。`0 0 1` 为向上拾音，`1 0 0` 为 +X。默认初始淡入 480 点（48 kHz 下 10 ms），回退通道是 CH0。
输出保留 8 点固定处理延迟以及尾部 8 点，长度为 `N+8`；文件最前 8 点为零。离线比较同时间音频时，将输出 `[8:8+N]` 对齐输入，并排除渐变和边缘补零部分。
CLI 使用整段固定方向，不能把它当作已集成实时自动跟踪。

## 应用接入接口

```python
from software.tetra3d.das.das_3d import TetraDAS

# geometry 与 Solver3D 构造时使用完全相同的配置。
beam = TetraDAS(geometry)
# result = solver.solve(locked_frame)
# valid_through 是应用明确换算后的 PCM 到期采样号，不是定位 frame.sequence。
beam.from_solver(result, valid_through=valid_through)
mono = beam.push(pcm_chunk, start_sample=0)
```

- `steer(direction, valid_through=...)`：手工或仿真指定方向；四路 Q12 延时作为返回值。
- `from_solver(result, valid_through=...)`：接收现有 `Solver3D.solve` 字典；检查 profile、geometry_source/revision、桥/API状态、方向有效位及向量。无效求解结果主动退回单麦。
- `hold()`：暂时保持原目标，不能刷新到期时间。
- `fallback()`：平滑退回 CH0；不是静音，也不是硬件紧急停止。
- `push(pcm_chunk, start_sample=..., final=False)`：消费 `(4,N)` S24 PCM，返回一维整数音频。连续调用必须带准确的起始采样号；错序/缺块直接报错，重新创建实例开启新会话。最后一次 `final=True` 排出尾部并关闭实例。

每个物理采样时刻最多更新一次控制，控制必须在 `push` 块边界应用；如在块中间到达，应拆块。更新只影响之后输出，不追溯修改已经输出的音频。
TTL 包含 `valid_through` 本点，下一点到期。渐变期间仅保留最新待切换方向，不无限排队；过期或回退可能先完成当前渐变再退回 CH0，最长约两个渐变周期（默认 20 ms）。若要求立即静音，应由下游另行实现。

错误格式/配置不一致会抛出异常，不能吞掉异常后无限续用旧方向；调用方应停止该会话或显式回退。来源/修订号只是防接错检查，不能替代应用确保几何内容一致。

当前不建立目标身份、音视频时钟对应或定位帧到 PCM 区间的映射。应用需负责：

1. 保证四路连续、同步 PCM，定义采样率、位宽、通道顺序及断流处理；六对相关峰摘要不能还原音频。
2. 将定位结果关联到相同采集会话和采样时间，拒绝迟到结果，合理设置 TTL；不要把到达时刻直接当采集时刻。
3. 对同一人的方向进行选择与三维平滑后再下发；本模块不自动从多人声音中识别目标。
4. 消费单声道输出到文件、播放器或声纹模块，另行约定重采样及幅值缩放。

Python 核心仍逐样本运行。低层 `DynamicDAS.push` 默认保持旧trace返回，显式 `trace=False` 可关闭；`TetraDAS` 已关闭原先会丢弃的逐点trace，预分配块输出并使用17槽环缓冲。样本历史最多17行不代表整个程序固定内存，也不代表能在ARM上实时运行。须在目标机测吞吐/耗时，必要时将数值核心移到C/向量化实现，以上接口与数值测试可继续复用。
