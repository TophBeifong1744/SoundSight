# 独立三维模块（二维主线之外）

本目录只在明确选择三维时使用，默认不接入二维采集、构建或发布包。

- `core/`：三维算法、几何配置及双轴软件映射。
- `linux/`：独立共享库构建、Python调用与离线回放。
- `tests/`：三维专用测试。
- [接合步骤](PS-MIGRATION.md)：给C的编译和验证入口。

## C的双核PYNQ应用接合

入口和串口步骤见[三维接合步骤](linux/三维接合步骤.txt)。CPU1唯一取帧并调用三维C库，CPU0保存完整结果。
`linux/run_buffered_3d.py`复用主线RAM队列及音量ABI检查；`linux/run_smp_3d.py`保留逐帧耐久确认；`linux/replay_capture_3d.py`兼容原始帧与现有采集日志。
三维方向为原始求解结果，不启用音量门限或动作。PC接合验证与ARM/实板状态见[本批证据](../../document/evidence/pynq-tetra3d-integration-20261021/REPORT.txt)。

仅只读复用 `../common/s1` 的公共类型及角度映射函数；不复制或修改二维实现。当前二维 `software/ps`、`software/tests` 与 `tools/package_pynq.py` 保持基线版本。现有二维发布包不会自动包含本目录。

# 算法说明

三维纯 C99 数学代码从原 STM32 成果移入，算法内容未改；没有 HAL、SPI、Keil 或板级时钟依赖。二维 `../common/s1` 与原 PS 二维入口保持不变。Linux 使用独立共享库，见 [ARM Linux 接合说明](PS-MIGRATION.md)。

已有模块：

| 文件 | 职责 |
|---|---|
| doa_solver_3d.c/h | S25/S6检查、RNE峰插值/峰间隔、资格过滤、三维LS、残差/范数/秩/条件数检查、方位和俯仰 |
| doa_geometry.c/h | 坐标与通道编号、标称/实测来源、尺寸误差上界和PL时差窗口检查 |
| doa_dispatch.c/h | 原C应用的二维/三维编译选择；Linux两个库由调用者明确选择 |
| doa_target_3d.c/h | 独立双轴角度映射，默认关闭，仅产生软件目标；无设备动作 |
| tetra40-nominal.json | 已确认的40mm正四面体标称坐标；未声称实测 |

坐标单位mm，+X前、+Y左、+Z上，原点为中心，底面水平，mic3在顶部。声孔中心坐标：

| 通道 | X | Y | Z |
|---|---:|---:|---:|
| 0 | 23.094011 | 0 | -8.164966 |
| 1 | -11.547005 | 20 | -8.164966 |
| 2 | -11.547005 | -20 | -8.164966 |
| 3 | 0 | 0 | 24.494897 |

六对固定01/02/03/12/13/23，模型 `tau_ab = (r_b-r_a) dot u * Fs/c`，u指向声源，对应 `Xa*conj(Xb)` 下 `lag=t_a-t_b`。48kHz、343m/s下单边最大延迟约5.597668样点；须与A实际PL的符号、通道和各对±6/±8搜索窗口核对。

数学范围是**远场单一主导声源方向**，不估距离，不做人声提取、声纹识别或多声源分离。3D采用double累计/3×3求逆、atan2，输出float与Q8角；2D继续使用原整数CORDIC，二者不是同一个数值合同。

研究默认：至少4个有效对、法方程无穷范数条件数≤100、残差RMS≤0.5样点、范数0.85～1.15、物理时差余量0.125样点。峰间隔会计算并报告，但不是新增的置信度拒绝门槛。参数未经实录标定。极点只使方位不可观测，俯仰仍可有效；不得拿无效方位0°驱动转台。几何来源标为MEASURED仅表示调用者声明，不是AI验证过实测。

目前完成数学实现及PC合成特征测试、Linux源码接口适配。实际ARM执行、三维实物阵列、实录准确率、真实双轴闭环均待完成。旧二维BIST用于传输检查，在三维求解器中返回 `DOA3D_LEGACY_BIST`，不能充当三维通过向量。
