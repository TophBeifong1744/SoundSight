## 推荐候选：U16无线模块插座

必须拔下无线模块；针脚号按原理图U16编号，不根据照片视角猜排针方向。

|信号|STM32 GPIO|外设/方向|U16针脚|FPGA连接器/封装管脚|
|---|---|---|---|---|
|SCK|PB3|SPI1 SCK，STM32输出|5|V7 / J4-5|
|CS_N|PG7|GPIO输出，空闲高|4|U7 / J4-6|
|MOSI|PB5|SPI1 MOSI，STM32输出|6|W8 / J4-7|
|MISO|PB4|SPI1 MISO，STM32输入|7|V8 / J4-8|
|IRQ|PG8|GPIO输入/EXTI8，FPGA输出|8|U9 / J4-9|
|GND|GND|共地|1|J4-37或J4-39|

FPGA侧映射来自用户转交的A截图，尚未由本侧对照准确底板原理图/XDC独立核实。

A补充：V7/U7/W8/V8/U9均属Bank 13；原理图默认VCCO为3.3V，没有占用当前四麦或舵机引脚。J4为实物照片下边缘、标有“7020 ONLY”的双排排针。具体编号起点/奇偶排仍按原理图及实物1脚标记确认，不能仅按照片上下方向推断。Bank供电若曾改动，以实际电压重新确认。

U16 pin2是板上3.3V电源，不作为信号；两板分别供电时不要顺手连接两板电源输出。pin3是PG6/NRF_CE，本协议不用。

## 使用条件

1. PB3/PB4/PB5与板载25Q128共用SPI1；在时钟活动前将PB14/F_CS置高，保持板载Flash未选中。软件不同时访问Flash。
2. PB3/PB4同时属于JTAG相关引脚；使用PA13/PA14的SWD调试，关闭占用PB3的SWO/Trace，不使用完整JTAG。
3. PG8同时接RS485_RE，不启用RS485例程，不将PG8配置为输出。原理图U16 IRQ路径带R66 1k串联电阻。
4. GPIO复用应为SPI1对应配置；SPI Mode0、MSB first、8-bit传输单位，软件CS连续包住5字节，等待最后一位真正发完后释放。IRQ按冻结合同为高有效保持电平，软件循环查询，不能只等待新的上升沿。
5. STM32原理图为3.3V逻辑侧；A确认FPGA Bank 13原理图默认3.3V，因此默认配置下电平方案匹配。上板前核实供电未改及XDC为LVCMOS33；若实际Bank供电改动则重新评估。两板分别供电并共地，不连接J4的3.3V/5V针，也不连接U16的3.3V针到对板电源。
6. 冻结初始SCK为1MHz。若采用常见168MHz系统、84MHz PCLK2，SPI1的二次幂分频无法恰好得到1MHz；S2须选择能满足冻结频率的合法时钟树或明确提出协议调整，不能把0.65625/1.3125MHz标为1MHz。本轮未配置时钟树，1.60ms仍是1MHz下纯线上预算。
