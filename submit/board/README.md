# 上板与现场资料

`scripts/`是实际板端启动脚本，`hardware/`为板卡/麦克风/接线原件，`instructions/`为当前安装和操作说明，`results/`为用户现场回报。`artifacts/ps_3d_latest_result/`保存当前匹配bit/HWH/XSA；私人声纹模型和档案不进入公开交付。历史Vitis与旧SD包不能当成当前部署。

从[三维SD说明](instructions/pynq-three-d-sd.md)、[W16更新](instructions/pynq-w16-update.md)、[声纹操作](instructions/pynq-speaker-3d.md)阅读；脚本在按[根README](../README.md)准备的工作目录运行。所有硬件命令仅供后续由使用者操作，本批未运行。

双轴用户观察见[手动回报](results/board-manual-result.md)，长期运行失败见[重启回报](results/board-unexpected-reboot.md)，短录入/评分见[声纹板测](results/speaker-enrollment-board-result.md)。
