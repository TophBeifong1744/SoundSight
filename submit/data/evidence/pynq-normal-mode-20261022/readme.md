## 证据边界

- 3000帧是离线假MMIO测试，3万帧是统计对象内存测试，不能标成实板长稳。
- 没有C/RTL/数值算法修改，因此沿用其已有测试边界，没有为这次纯Python入口启动XSim/综合/实现。
- 正常模式无逐帧写SD，原debug的3000帧高水位问题仍未修复；不能因为有normal模式就把旧失败关闭。
- 突然断电/进程强杀可能丢本次汇总；正常退出才写盘。显示堵塞可能跳过输出，`console_skipped`计数；不保证操作系统硬实时。
- 失联或C/驱动挂死时请求STOP；强制终止子进程则明确报告STOP未经确认。故障时保留锁帧，后续debug排空取证，不静默清故障。
- 当前仅作者必要自测，未作非作者独立签核，未提交远端或宣称整机验收。
