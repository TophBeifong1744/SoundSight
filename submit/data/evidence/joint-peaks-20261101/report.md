# 多录音联合选峰研究 — 2026-11-01

本轮找到一个值得保留的离线候选：**筛选相位一致的频点后进行16帧积累**（coherent16）。在五份现有录音上，全段有效窗口比例均高于原算法；静止B的5个反向离群未在该候选中出现。不过背面俯仰偏差仍约+18°，本人语音的有效方向中位偏差也未改善，尚不具备替换板端算法的依据。

没有修改产品、位流、门限、声纹参数或板端，没有使用ILA，没有要求新录音。本轮交付是离线代码、数据和结论。

## 固定比较方法

运行前将范围写入PLAN.md。保留原40mm正四面体、至少4对、原时差物理边界、残差≤0.5采样点、模长0.85–1.15，不通过强制归一化把坏结果变成有效。

比较原生产C回放和六个PCM浮点方法：单帧基线、PHAT16、原互谱平均16、相位一致性支持16、单帧双峰联合选择、16帧双峰联合选择。几何C结果沿用前轮回放；PCM与原C少量差异已在各录音报告保留。

coherent16复用此前study_weighting.py中的既有固定方法，本轮未调参：

1. 各窗按原频带/能量门禁生成PHAT频谱。
2. 只使用当前及此前最多15帧；遇到序号间断清空对应历史。
3. 每对每个频点至少观察到4次，归一化复相位的集中度至少0.7；否则不参与。
4. 频谱积累再乘相位集中度平方，降低不稳定频点影响。
5. 保留每对至少12频点以及原解算器的物理、残差、模长检查。

这不是简单平均最终角度，也不是修改声纹计算。

## 同输入结果

分母为原分析音量门限以上窗口。各窗口重叠，不是独立试验；“有效”是通过算法检查，不等于方向正确。

| 数据 | 原C有效 | 旧PHAT16 | coherent16 |
|---|---:|---:|---:|
| A前方静止，1015窗 | 218（21.48%） | 34（3.35%） | **342（33.69%）** |
| B背面静止，1021窗 | 438（42.90%） | 582（57.00%） | **640（62.68%）** |
| B动态，1022窗 | 208（20.35%） | 262（25.64%） | **255（24.95%）** |
| 本人语音，593窗 | 28（4.72%） | 119（20.07%） | **114（19.22%）** |
| C语音，276窗，条件不明 | 14（5.07%） | 68（24.64%） | **31（11.23%）** |

coherent16相对旧PHAT16牺牲了部分语音/动态有效率，但避免了A轮明显退化。尚未构成所有方面的胜出。

| 有效方向指标 | 原C | coherent16 |
|---|---:|---:|
| A方位/俯仰中心 | +5.52° / +2.96° | +7.83° / +0.95° |
| B静止方位/俯仰中心 | -179.94° / +17.71° | +179.01° / +17.59° |
| 本人语音方位/俯仰中心 | -12.71° / +10.16° | -8.25° / +11.05° |
| B静止相对预期背面超过90°的有效窗 | 5 | 0 |

用户同高布置的B俯仰偏差基本没变。本人语音相对近似前方的有效方向角偏差中位数14.59°→16.35°，P90为36.09°→28.83°；不能只报有效率改善，声称定位精度全面提高。这些角度参照用户描述的约略方向，并非仪器测量真值。

本轮还检查了前后半段：B静止前半段有效数206→203、后半段232→437；C前半段5→4、后半段9→27。收益不均匀，尚未证明不同时间/环境均稳定改善。

coherent16的模长拒绝仍很多：A669窗、静止B366窗、动态B578窗、本人语音315窗。改善频点不足/残差问题并不等于消除了几何不一致。

## 双峰联合选择为什么淘汰

固定次峰条件为原扫描范围内局部极大值、峰高至少为主峰80%，每对最多2峰；原结果不合格时枚举至多64组合，通过原几何检查后按有效对数、相对峰高和残差排序。

- 单帧A浮点基线218→219，但新增的1窗是反向离群。
- 单帧静止B434→443（原C为438），反向离群由5→6。
- A和静止B的16帧频谱都没有满足条件的次峰，联合方法与旧PHAT16结果完全相同。

这说明在目前扫描范围和峰高条件下，单纯换一个次峰没有解决主要问题，反而会把另一组几何上可行的错误峰放行。该分支不作为产品候选。不能进一步把峰高或几何门限放松来制造有效率。

## 主机验证与限制

- 五个已知理想方向×六个方法：积累稳定后均通过几何检查，最大角偏差均小于1°。这是合成理想互谱，不是带真实反射的声场。
- 静音：六个方法各128窗均0有效。
- 四组独立、400–3800Hz带限且音量充足的通道噪声，共2040窗：coherent16为0有效；PCM单帧基线90有效。有限构造负例不能外推为零误判率，也未覆盖多声源/相干反射/真实噪声。
- 因果性：8个不同长度的前缀与完整回放对应输出完全一致；序号间断后的输出与全新历史启动一致。
- 理想突然换方向：第40帧切换0°→180°，40–42帧仍输出接近旧方向，43–51帧拒绝，52帧首次恢复接近新方向，按512/48kHz步长相当于切换后128ms。这是合成频谱序列的算法响应，不是实麦/舵机延迟，不可当作旧许可或运动安全验收。
- 16帧覆盖181.33ms音频，最老窗比当前窗早160ms，等权历史中心相对当前窗名义上增加80ms。实际权重依赖频点，真实响应不固定为80ms。
- PC统计耗时不包括完整采集、全部FFT及板端并发，不能换算成PYNQ实时性。现有硬件定位快照不含完整频谱，部署需要复用PCM路径或调整前端，不能只替换最终C解算器。

## 下一阶段建议

保留coherent16作为候选，先从已有A/B的原始频谱检查背面俯仰偏差来自哪些对、哪些频段；保持几何及门限不变，不用直接减18°的方式掩盖方向依赖偏差。之后再决定可部署的计算路径与接口。当前不需要用户再录音，也不发更新包或承诺板端实时性。
