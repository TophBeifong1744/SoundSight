# MATLAB 黄金模型

本目录用于建立独立于 RTL 的算法参考和测试向量生成器，覆盖：

- 根据阵列坐标、DOA、声速和采样率生成多通道整数/分数时延信号；
- 加入可控白噪声、相干干扰和简化混响；
- GCC-PHAT、合法 lag 搜索、亚采样峰值与 TDOA；
- 阵列几何到 DOA 的求解与置信度；
- 浮点到定点的逐级误差、范围和溢出统计。
- P50/P95 角度误差、有效输出比例、错误指向比例和无效原因统计；
- 通道对质量加权与 SRP-PHAT 的离线候选比较，结果未证明改善前不进入 RTL。

模型脚本应显式保存采样率、阵列坐标、声速、随机种子和算法参数。导出的测试向量使用简洁、版本化的格式，并在头部记录单位与定点表示。

当前首个入口：`square_array_baseline.m`。它只核对历史40 mm方形阵列的传播时差与角度量化数量级，不代表当前正四面体或房间实测性能。
