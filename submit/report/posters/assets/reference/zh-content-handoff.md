## 1. 内容取舍结论

项目主线是：会议中发言位置和次序不断变化，系统通过四麦阵列获取声音方向，结合可选的说话人验证，控制双轴指向。最终产品还包括触摸操作和定向拾音；后续面向机器人等具身智能设备提供方向与说话人信息。

建议突出两项贡献：

| 核心贡献 | 本项目应强调什么 | 原创边界 |
|---|---|---|
| 正四面体四麦三维测角 | 非共面几何、六对时差约束、亚采样插值、三维求解与方向筛选的具体实现，以及 PL、PS 的协同处理 | 正四面体几何、互相关、最小二乘属于已有方法；贡献在于实现和系统设计 |
| 连续方向更新与异步声纹授权 | 将耗时较长的声纹计算与方向更新分开，使用限时许可参与双轴控制 | 属于本项目的控制与调度设计；不等于推理提速，也不保证多人身份与方向严格绑定 |

RGB 触摸交互、DAS 拾音和双轴执行构成完整产品设计。CAM++、Silero、DAS 方法及厂商 FFT/IFFT IP 应按已有组件说明。

结果区建议采用**“两轮板端联合运行”表格**，替换目前占据主要位置的前端优化柱状图。它更直接回应系统是否能够共同运行。前端耗时优化有真实依据，但属于局部计算优化，可保留在报告中展开。

海报不再展开 READY/LOCKED、寄存器、日志字段、逐条命令和排错历史。现有证据也不足以提供定位误差、识别准确率、拾音增益或机械到位性能曲线。

### B. 左栏“项目简介”

**应用背景与价值：**

> 会议发言者的位置与次序不断变化，固定指向设备需要反复调整。SoundSight 首先服务会议发言者指向，后续面向机器人等具身智能设备，提供声源方向感知与说话人身份信息。

**典型应用流程图标题：**

> 典型使用流程（最终设计）

四个节点依次排列：

| 节点名称 | 节点说明 |
|---|---|
| 选择模式 | 触摸设置；声纹模式选择已录入模板 |
| 发声测向 | 四麦同步采集，计算方位角与俯仰角 |
| 判断跟随 | 按方向跟随，或增加声纹许可条件 |
| 指向与拾音 | 双轴调整指向，按方向合成拾音并显示状态 |

排版说明：第四步中的机械指向和音频合成是两项并行功能，不画成“转动麦克风后才开始拾音”。触摸与拾音的接合状态统一在中栏图注说明。

**系统概述：**

> 系统以 Zynq-7020 实现声音感知与指向控制。PL 承担同步采集、频域相关和双轴 PWM，PS 执行三维求解、声纹验证与跟随决策；最终设计通过 RGB 触摸屏完成本地操作，并以方向引导定向拾音。

**关键技术问题与设计要点：**

- **空间测角：**非共面四麦提供水平与垂直方向约束，输出方位角和俯仰角，不估计距离。
- **任务协同：**定位持续更新，声纹异步计算，通过结果在有限时间内参与跟随决策。
- **执行控制：**方向质量、运动范围与模式条件共同决定动作，默认不开轴，保留停止和超时保护。
- **功能接合：**定向拾音同时接收同步音频与有效方向，触摸交互贯通配置与状态反馈。

### C. 中栏“系统结构与创新设计”

以下模块与连线说明供排版使用，不需要把整张说明表放上海报。

| 所属区域 | 框图节点文字 | 职责与连接 |
|---|---|---|
| 输入 | 正四面体四麦 | 声音输入，连接 PL 同步采集 |
| PL | 同步采集 | 产生四路同步音频，分别送相关运算和音频传输 |
| PL | 相关特征 | FFT、PHAT、IFFT 及六对相关特征提取，送 PS |
| PS | 三维求解 | 根据相关特征计算方向，进行质量与多帧筛选 |
| PS | 声纹验证 | 从音频提取特征，与所选模板比较，生成限时许可 |
| PS | 跟随决策 | 根据方向、运行模式及许可条件生成双轴目标 |
| PL | 双轴 PWM | 接收目标命令，产生 PWM，执行停止和超时保护 |
| 输出 | 双轴机构 | 按水平、垂直目标调整指向 |
| PS 拟接入，虚线框 | DAS 拾音 | 输入四路 PCM 和有效方向，输出单声道音频 |
| 外设，虚线框 | RGB 触摸屏 | 经显示、触摸接口与应用交互，完成操作与状态显示 |

连接必须明确画出：

```text
正四面体四麦 → PL 同步采集 → PL 相关特征 → PS 三维求解
                                      六对特征／AXI

PL 同步采集 → 四路 PCM／DMA → PS 声纹验证
                           └→ DAS 拾音〔待接合〕→ 单声道音频

PS 三维求解 → 方位／俯仰 → PS 跟随决策
PS 声纹验证 → 限时许可 → PS 跟随决策〔仅声纹模式〕
PS 跟随决策 → 角度命令 → PL 双轴 PWM → 双轴机构

PS 三维求解 → 有效方向 → DAS 拾音〔待接合〕
RGB 触摸屏 ⇄ 操作／状态 ⇄ PS 应用〔待接合〕
```

图中用箭头标签区分音频、定位特征、方向、许可和控制命令。**双轴 PWM 必须归入 PL。**触摸屏与 PS 的连线表示应用层关系，不能据此推定已经确认了电气接口或显示控制器。

**框图下方图注定稿：**

> 虚线部分待整机接合验证；DAS 已有 PC 参考实现。声纹当前使用单路音频，未接入 DAS 输出。

**上方圆角框红色小标题：**

> 正四面体四麦三维测角

正文：

> 正四面体四麦的非共面布局形成六组时差约束。PL 提取通道间相关特征，PS 通过亚采样插值、最小二乘求解和方向筛选，计算声源方位角与俯仰角。阵列几何、求解程序与软硬件处理链路共同构成三维测角方案，为双轴指向和定向拾音提供方向输入。

**下方圆角框红色小标题：**

> 异步声纹授权跟随

正文：

> 声纹异步计算，通过后在限时内允许双轴按新方向更新，避免动作逐次等待推理。许可作用于当前声源方向，尚不保证多人场景下的身份与方向绑定。

> 测试采用同一目标模板，声纹试验门限为 0.45、许可时长为 10 s，两轴同时启用。两轮停止前各完成 6 次声纹计算，方向通路在其间持续更新。第二轮淘汰 1 个旧定位结果；当前证据尚不能给出角度误差、身份识别准确率或长期稳定性结论。

**后续完善方向：**

> 补齐方向与指向误差、他人声纹对照、实麦拾音及触摸操作验证，再拓展机器人听觉交互。

## 5. 需要三边同步纠正的共同事实

1. **应用主线统一。**中文 v4 仍将会议、教学、交互终端并列；应改为会议发言者指向优先，机器人等具身智能设备作为后续重点。英文海报同步调整。
2. **创新重心统一。**突出正四面体四麦测角实现和异步声纹授权；队列保新留在工程实现与优化论证中。
3. **框图分工统一。**PWM 属于 PL；PS 负责目标计算与提交。DAS 必须同时接收四路音频和方向，不能只画一条 PS 控制线。
4. **身份与方向关系统一。**使用“声纹授权跟随”，不写“精准锁定指定说话人”“只跟随本人”或“已完成多人身份与方向绑定”。
