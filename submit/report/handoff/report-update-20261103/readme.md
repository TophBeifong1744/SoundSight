# 技术报告、设计报告与双语海报更新入口

本轮归档最新板端日志、用户更正后的实测工作簿、整机照片和用户指定协作TXT，统一当前程序、证据和写作口径。三个聊天分别修改自己的稿件，不覆盖另外两项的生成源和成品。

1. 共读 [事实与数据](facts.md)、[总指导](../../requirements/report-poster-master-guide.md)、[最终范围](../../requirements/final-report-scope.md)。
2. 技术报告使用 [提示词](technical-prompt.md) 和 [Word模板](../../requirements/technical-report-template.docx)。
3. 设计报告使用 [提示词](design-prompt.md)、[七项要求](../../requirements/design-report-requirements.jpg) 和 [评分权重](../../requirements/design-report-scoring.png)。
4. 中英文海报使用 [提示词](poster-prompt.md)、[PPT参考](../../requirements/poster-reference.pptx) 和 [版面参考](../../requirements/poster-reference-annotated.jpg)。

最新原件：[声纹双轴连续运行、整机照、协作TXT](../../../data/evidence/final-board-20261103/readme.md)。历史对比：[界面与SOUND测试](../../../data/evidence/report-measurements-20261103/readme.md)、[声纹优化指标](../../../data/evidence/speaker-report-materials/readme.md)。工程图和实现结果使用[11月3日S2导出](../../../build/reports/current/screen_s2_20261103/readme.md)。

本轮不代写或覆盖在途Word/PPT；更新后的报告、海报仍由各自聊天生成与视觉检查。材料包保持仓库相对目录，可解压到独立目录阅读。`submit/`另包含源码、验证、匹配硬件及复现资料。

补测原表及更正、CSV和复算JSON均在[统一证据目录](../../../data/evidence/final-board-20261103/readme.md)。三个聊天采用同一facts.md，不分别猜测表格阵列或数据来源。
