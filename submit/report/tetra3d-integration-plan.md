## 当前分工与共同接口

| 责任 | 当前成果方向 |
|---|---|
| A：三维 | 实际阵列坐标/通道核对、ARM三维求解、方位/俯仰显示与筛选、本次双轴硬件及软件；DAS另做效果验证 |
| B：声纹 | P02模板与门限、推理速度、身份有效性、对外实时结果接口及可持续运行的算法服务；保持完整成果责任 |
| A侧集成 | 维护唯一采集入口与共享接口；将两边成果接入、按同源采样范围关联并测组合负载 |

1. 输入继续共用四路48kHz、S24-in-S32、小端交错PCM；每包512个四通道采样帧，32字节头+8192字节数据。B当前固定mic0，不依赖三维结果。阵列改形但通道/格式不变时接口可复用；mic0位置、声学响应变化后仍需复测识别效果。
2. 只有一个采集服务持有设备锁、DMA和定位快照的锁槽/消费/停止权。它分发PCM给声纹、六对特征给三维；算法内部算不过来可以按约定替换未计算窗口，不能任意丢PCM假装连续。两套独占诊断命令不能同时跑。
3. 三维输出方位角、俯仰角及各自有效位；声纹输出目标标识、相似度、身份状态、可用性、来源采样区间和时效/撤销信息。声纹分数不是概率，eligible不是本人许可。当前P02只有分数，不能驱动“只跟随本人”。
4. 关联使用相同epoch和采样区间。声纹16kHz窗口与定位48kHz窗口需显式处理降采样映射、FIR延迟和时间原点；不能拿3秒前声音的身份配当前角度。重叠多人场景中，身份与方向是否属于同一人还需另证。
5. 两边先各自测试，组合后再测CPU争用和连续性。当前声纹会用两个CPU核，不能按“一核三维、一核声纹”默认互不影响。接口或PL变更时共同同步，保留可运行基线；不要求普通声纹优化逐项交A审批。

其中声纹逐次结构化结果通道在新包中尚未实现；字段及有界传输方式是下一接合项，不冒充已冻结接口。

## 第一阶段只接三维测角，默认无动作

在保持同一四路采集接口、48kHz采样、六对顺序及数值格式的前提下，当前PL的六对时差特征可用于三维求解。对于B的40mm名义四面体，最大理论时差约5.60样点，处于现有各对±6/±8搜索范围内。因此以复用现有Vivado工程和位流为首选；这是接口可复用的判断，不是三维实板验收。

必须先具备真实非共面四麦阵列，核对声孔xyz坐标、物理通道0～3、坐标朝向和时差符号。原平面阵列不能只改JSON坐标就得到可信俯仰。若实际阵列尺寸、采样率或通道接口变更，重新检查搜索范围与接合条件，不能无条件承诺继续使用旧位流。

后续PYNQ侧工作：

1. 在目标ARM环境编译独立`libss_solver_3d.so`并运行数值与接口测试，保留原二维库。
2. 增加明确选择的三维运行入口，复用原采集所有权、锁槽/消费、音量门限、故障与停止机制。
3. 接入方位角、俯仰角及各自有效位，适配显示、日志和多帧筛选；不能把二维`angle_q8`直接替换成其中任意一轴。极点方位无效时不可把0°当有效方向。
4. 以已知方位/高度的真实声源完成有界无动作试验，验证通道、左右/上下方向、拒绝原因和处理耗时。旧二维BIST保留为传输检查，不能冒充三维算法通过。

这是A侧下一条可独立推进的路线，无需等待B完成声纹识别。本轮尚未执行以上板端动作，也未向B发送新任务。

## DAS和双轴各自的边界

DAS以后可以复用现有PCM CDC通路：四路S24以小端int32交错传输，转换为`(4,N)`数组后按epoch和采样范围对齐三维方向。先验证ARM吞吐和实录效果，再决定是否作为声纹前处理；DAS不是声纹识别，也不能用合成降噪效果替代真实识别验证。为了当前两条任务独立推进，B先继续使用原mic0，DAS不作为声纹前置依赖；以后换输入时再复测模板、门限及延迟。

双轴跟随不属于“只换PYNQ软件”范围。当前`bd_ps_link`的垂直PWM固定为低电平，仍需在本次完整三维实现中补齐RTL/接口及保护、标定，并由用户运行综合实现。已确定水平T15、垂直W15的引脚约定保留；本轮进度核查尚未修改或启用任何执行器。硬件具备两轴能力后，由PYNQ决定是否开启以及使用手动或跟随模式。
