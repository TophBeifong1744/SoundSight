# PS双轴控制扩展 v1

2026-10-28，用户确定三维测角与水平/垂直跟随一次完成，开关由PYNQ控制。仅扩展PL+PS，不改变STM32冻结SPI合同。水平T15为0～360°，垂直W16为0～220°；两只均按用户确认采用20ms周期、500～2500μs脉宽。机械零位、方向和更窄的允许范围由PYNQ标定。

本文件定义实现接口，不代表综合、实现或板测通过。`DUAL_AXIS_ENABLE`默认0，复制工程更新脚本设为1；冷启动、ARM前后均无自动PWM，首次合法COMMIT才可能产生输出。原0x00～0x94、PCM、快照、STATUS位布局和二维入口保留。

## 寄存器

地址均为`ps_link`基址内的字节偏移，32位、4字节对齐、完整字写。两角/两限位分别使用`H或min[8:0]`和`V或max[24:16]`，其余位必须为0。配置角度以整数度表示。

| 偏移 | 读 | 写 |
|---|---|---|
| 0xA0 | 能力`0x44554101` | 只读 |
| 0xA4 | 0 | 0撤许可；1 ARM_MANUAL；2 ARM_FOLLOW；3 COMMIT；4 APPLY_CONFIG |
| 0xA8 | bit0 active、bit1 follow、bit2有已接受命令、bit3水平排尾、bit4垂直排尾、bit8水平配置使能、bit9垂直配置使能 | 只读 |
| 0xAC | 双轴目标影子 | 水平[8:0]、垂直[24:16] |
| 0xB0 | 水平限位影子 | min[8:0]、max[24:16] |
| 0xB4 | 垂直限位影子 | min[8:0]、max[24:16] |
| 0xB8 | 轴使能影子 | bit0水平、bit1垂直，1/2/3选择轴 |
| 0xBC | 跟随序号影子 | 完整32位当前锁帧序号 |
| 0xC0 | 最后接受的双轴目标 | 只读；不是机械位置反馈 |
| 0xC4 | 最后接受的跟随帧号 | 只读 |
| 0xC8 | 750ms硬件租约剩余时钟数 | 只读 |
| 0xCC | 已应用的水平限位 | 只读 |
| 0xD0 | 已应用的垂直限位 | 只读 |

扩展未启用时0xA0以后的新寄存器不属于有效地址。不要给旧位流写扩展探测命令；先按HWH的`DUAL_AXIS_ENABLE=1`选择新客户端。既有能力位19仍表明水平动作硬件绑定，不能代替双轴A0版本核对。

## 配置、模式和原子性

1. 两轴停用、两轴已排尾且旧水平跟随/旧手动通路均空闲时，写B0、B4、B8，再向A4写4。三项必须在本次配置中都写过；范围满足0≤Hmin≤Hmax≤360、0≤Vmin≤Vmax≤220，轴mask非0。三项一起生效，任何错误都不能只改一轴。采集运行不妨碍此配置步骤。
2. 手动：采集/BIST关闭、计算排空、无待消费快照，向A4写1。此模式不读声音或声帧。跟随：真实采集已开启，向A4写2；不能在BIST模式ARM。
3. 每次ARM后，再写AC；跟随还要写BC。向A4写3同时提交已启用轴的目标，整组检查通过才接受。COMMIT成功后需重新写AC，跟随还需重新写BC，不能用反复写COMMIT保持旧命令。未启用轴的角度不参与范围检查，建议填0，该轴保持低电平。
4. FOLLOW要求当前锁定真实帧、至少4个原始合格麦对、影子序号等于当前32位序号且不等于上次接受序号。三维数值、空间资格、音量、多帧筛选由PS负责；硬件检查不能替代三维算法。
5. 软件可在下一帧用同一个经过筛选的角度续约，但必须继续通过本帧资格与软件的新鲜度检查；过期方向不能靠新帧号无限续命。

ARM只建立750ms租约；首次合法COMMIT后才开启PWM门。两路复用同钟同复位的`motor_drive`，目标同拍进入同一20ms周期边界；边界同拍到来的目标沿用原模块规则，在下一完整周期生效。首次开门沿用原guard等待规则，不输出旧复位角度或半个高脉冲。

## 停止、失效和恢复

- A4=0仅撤双轴许可，不停止测角采集，不自动置取消故障；当前已输出的高脉冲完整结束，禁止新高脉冲。
- 旧SYS停采集、旧ACT的0/STOP/REVOKE、PS总线复位、硬件故障均撤双轴；STOP同拍COMMIT不得接受。
- 750ms内没有合法COMMIT，撤两轴并在原FAULT bit8记录超时。非法ARM/COMMIT/配置应用沿用bit7拒绝；格式/只读/活动时改配置沿用bit1寄存器错误。
- 两轴共享一组许可和租约；不会出现一轴目标被接受、另一轴因非法而未更新的半提交。mask只能停用并排尾完后重新原子配置。
- 普通总线复位撤许可、清配置和目标影子，保留已保存快照以及最后使用的跟随序号；不能在复位后重放仍锁着的旧帧。冷复位可清序号并立即拉低PWM。
- 恢复必须查明故障、按原流程处理快照/清错、必要时重新配置，再显式ARM和新命令。程序启动、位流加载、角度合格均不能替用户开启转台。

没有机械位置反馈。“COMMIT接受”和“PWM正确”均不等于机械已经到位。
