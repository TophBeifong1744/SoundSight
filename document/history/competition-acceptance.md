# 2026 FPGA 赛道要求与项目验收台账（迁移快照：2026-09-23）

本台账依据 AMD《2026 FPGA 赛道选题指南》中第三赛道初级组要求建立，用于区分“已由团队确认”“由照片或文档部分确认”和“必须靠工程或板测证明”。计划、模型、仿真、综合时序和板上实测是不同证据等级，不得互相替代。

V1 总验收改为 10/7；[统一日历](project-plan.md)是团队内部计划，不代表比赛官方截止时间。既有指南版本、页码、哈希与条款见[Skill计划](skills-delivery-plan.md)，本次未复查官网修订。A/B/C 平等承担工程任务，动态状态以 GitHub Issue/PR 为准。

Skill 的统一制作流程为：

```text
赛题与实际失败映射
  -> 定义触发条件、输入、输出与停止条件
  -> 编写最小 SKILL.md 和赛题说明 README
  -> 只添加真正复用的脚本或参考资料
  -> 离线/隔离样例测试
  -> Skill 静态验证与英文路径检查
  -> 实板或跨项目前向验证
  -> 记录效果、失败边界和人工修正
```

赛题3.3.3.1和3.3.5.2要求提交可复用Skill及可见AI交互记录，未规定必须两项；本队决定交两项。3.3.2和3.3.5.2明确通用PYNQ Skill单独加分；3.3.6的15%是LLM协作与Skill合计权重，额外分值未公布。SKL-001主打RTL/TB与真实仿真调试闭环；SKL-002主打DMA缓存/失败收尾和精确golden。二者须从实际失败与独立复用证明收益，不保证分数、不替代作品功能/资源优化/板测。

## 4. 当前阶段结论

六麦模型证据补充：依用户授权，仅六麦的2700帧浮点模拟及21项自检已运行，沿用原麦克风路线；未做四麦模拟。低带内SNR和等强竞争声源有明显失败，见[六麦软件预评审](six-mic-acoustic-software-review.md)。仅登记合成预研，现有强制工程项仍不得改成通过。

范围补充：V1仍按四麦验收冻结场景内的二维水平DOA和音频改善。三维方向（方位、俯仰和单位向量，不含距离/高度数值）列为V2：六麦为首选候选，非共面四麦为低成本备选，八麦暂缓；数量尚待声学与资源评审。当前已形成指南、预留规划与六麦首轮合成软件证据，不增加赛题强制要求、不影响V1是否通过。三维能力按[三维方向升级计划](three-dimensional-doa-plan.md)的3D-G0、扩展采集准入3D-GA、3D-G1～G3另行验证；四路通过不等于六路通过，指南/Skill/模型不能替代实板证据。

当前已有H1共同确认、四路短诊断接收、current_build限定批准和局部算法/RTL研究，不再写“没有真实四通道录音”。仍缺完整V1算法H3、正式M1、真实二维定位/音频收益、整机资源/时序/吞吐及从零交付证据，见[当前状态](current-status.md)。PYNQ实板准入未通过，合同兼容PS替代路径保留。精细待补证只按[暂缓清单](deferred-acquisition-risks.md)处理，明确安全冲突仍处理。两项 Skill 按 #21/#22 及新日历完成，A 制作、B/C 分别独立复核；不重复从零制作。
