# 采集补证暂缓记录与执行规则

2026-09-10，依据拓芙最新决定：先推进功能，电气/时序精细补证先记账；遇到常规排查难以解决的问题，再按症状回查。本文优先于旧补证报告中的“下一步立即补齐”“补证前只做单麦有限收尾”等执行安排。

## 现在怎么做

- 继续采集功能、数据导出、通道扩展和算法联调，不把下面的精细补证作为日常开发前置任务，不为它们单独安排仪器测量或反复重录。
- 扩展通道仍依据已知引脚、供电和接线资料实施；这条规则不是允许猜接未知接口。电源接错、短路、异常发热等明确安全问题立即处理，不等到“难以解决”。
- 正常保留当前代码、配置和测试输出即可，不追溯重建已经缺失的历史加载证据。
- 三个交接点和 A/B/C 分工不变。按实际观察记录功能结果；“功能运行正常”和“最坏电气/外部时序保证”分开表述，后者暂未验证不自动阻塞前者。

## 先记下、不主动催办

| 暂缓事项 | 已有记录 | 何时回查 |

| DATA 电平规格兼容与实际模块/负载 | 3.3 V 比例边界比较不能建立最坏兼容保证；不等于实物已误码 | 随机错码、爆音、换模块/线缆后不稳定，且格式、软件和接线常规排查无解 |

### 2026-09-11：C 转接板非阻塞风险（唯一跟踪位置）

拓芙已决定[采用 C 转接板](../hardware/microphone-adapter-decision.md)，工程适配四路同源 CLOCK 输出和四路独立 DATA，不再做采用与否的方案比较。下列事项全部为“记录、暂缓、未验证”，不是已发现故障，也不是四路开发前置条件；无单独截止日、不定期催办。负责人 A 按症状处理，B 仅在需要声学/算法判断时协助；不转交 C 开放研究。

| 编号 | 暂缓事项及当前边界 | 何时回查 / 最小动作 |
| --- | --- | --- |
| CBR-01 | 四 CLOCK 实际边沿、反射、偏斜和 DATA 有效窗口未测；同源逻辑不等于物理零偏斜，四路也不自动优于单路分配 | 扩路、换线或改变取样相位后出现难定位错码/通道异常，再针对相关 CLOCK/DATA 比较；需要时再决定阻尼或缓冲，不预先改板 |
| CBR-02 | 四模块供电负载、纹波、地回流、探头负载与最坏电平裕量未完整核实 | 排除格式/接线等常规原因后仍有噪声、复位或不稳定，再测相关电源/信号；沿用上方 VDD/VCCO 记录，不重复开单 |
| CBR-03 | 2.0 mm 针距和声孔面已有资料；精细排间距、插接高度、振动固定、声孔净空余量尚未全量记录 | 首次装配若不贴合、晃动或堵孔，针对实际位置修正；不为文档齐全重拍已有照片、不无故要求转接板开孔 |
| CBR-04 | 名义约40 mm不代表实测声孔坐标、最佳间距、相位/增益一致；本版不要求35～50 mm可调 | 后续定位/标定或方向符号出现问题时，测必要坐标并核对实际通道与朝向；短诊断阶段未知坐标照实填未知，不改阵列来满足旧模板 |
| CBR-05 | 已有原始epro2与本轮哈希；本轮网络解析不是原生EDA ERC/DRC、制造或实板验收 | 实际准备制造时复用或导出当前版本必要检查；出现具体冲突再处理，不为当前代码开发提前追加全套制造报告，不以“采用”冒充检查通过 |
