# 需求与验收范围

2026-10-29按用户决定：**唯一主方案为Zynq-7020（PL＋PS/PYNQ）；STM32路线已弃用。** 路线选择不代表现有功能已全部验收，也不取消有效失败事实。

## 当前主线

四麦40mm正四面体三维声音定位、连续测量、水平/垂直双轴控制、可选声纹许可；二维代码保留作基础对照。PL负责采集、相关特征/PCM和硬件运动保护，PS在同一双核Linux/PYNQ中完成C求解及Python业务。现行PS接口见音量、PCM及双轴接口说明；共享六对顺序、lag符号、数值和STOP保护继续有效。冻结SPI合同只约束保留的历史STM32实现，不要求当前主线重新验收跨板SPI。

`follow-sound`是用户明确选择的纯声源模式；`speaker`及`run --axes`需要声纹许可。默认不开轴，手动标定独立。六麦研究不进入当前主线。架构与操作入口见[当前架构](../main-architecture.md)。

## 仍需闭合的验收项

| 项目 | 应有的结果 | 当前边界 |
|---|---|---|
| 三维定位 | 实测通道、几何/lag方向，参考方位/俯仰、误差、有效率、响应时间 | 有数值和实麦记录；真实三维声学精度尚未验收 |
| 连续处理 | 持续运行、无非预期丢帧、资源有界、故障停止与恢复 | 二维千帧已有证据；最新双轴长稳发生整板重启，原因未定 |
| 双轴闭环 | 标定后的零位/正反/范围、跟随、限位、超时与STOP | T15/W16手动转动已由用户确认；全行程和长期闭环未验收 |
| 工程可实现性 | 同候选资源、setup/hold、CDC/RDC、I/O/DRC和约束覆盖 | 最新W16实现时序及限定补查已有报告，不代表板端长稳通过 |
| PS软件通路 | 真实ARM/PYNQ运行、共享库/采集接合、调度和停止恢复 | 已有ARM与板端运行；PC离线测试不能替代目标板长稳 |
| 声纹许可 | 本人/他人独立评分及门限、失败/静音/过期撤销、身份方向关联 | CP1/VF1与许可接合已做；完整识别效果和关联验收未完成 |
| 定向拾音/声音改善 | 若纳入最终展示，需同输入对照、真实PCM/DAS与听音结果 | 已有PCM导出与DAS软件；不能声称DAS已用于最终声纹输入或实物降噪达标 |
| 可复现与交付 | 匹配的BD/PS/IP、源码、bit/HWH、环境与可执行说明 | 已有交接和SD包；后续跟随候选变化维护，不把打包当整机验收 |
| 比赛材料 | 对应实际候选的报告、照片/视频、授权和真实AI协作材料 | B补充资料已归档；缺失实物材料不能用历史软件结果替代 |

不新增未经确认的角度误差阈值、长稳时长或资源余量百分比。STM32 S2、跨板SPI和旧机构任务不再作为当前完成条件；历史成绩、失败记录和贡献归属原样保留。
