# 需求与验收范围

2026-11-02更新：**唯一主方案为Zynq-7020（PL＋PS/PYNQ）**，最终四项功能及组合以[统一说明](../final-function-scope.md)为准。范围确定不代表全部验收，也不取消有效失败事实。

## 当前主线

RGB触屏交互、四麦40mm正四面体三维定位、声纹验证和水平/垂直双轴指向。PL负责采集、相关特征/PCM和运动保护，PS在同一双核Linux/PYNQ中完成CF1A前端、C求解、声纹及交互调度。二维保留作基础对照；共享六对顺序、lag符号、数值和STOP保护继续有效。冻结SPI合同只约束历史STM32实现，不要求当前主线重新验收跨板SPI。

`follow-sound`是用户明确选择的纯声源模式；`speaker`及`run --axes`需要声纹许可。默认不开轴，手动标定独立。六麦研究不进入当前主线。架构与操作入口见[当前架构](../main-architecture.md)。

## 仍需闭合的验收项

| 项目 | 应有的结果 | 当前边界 |
|---|---|---|
| 三维定位 | 实测通道、几何/lag方向，参考方位/俯仰、误差、有效率、响应时间 | 有数值和实麦记录；真实三维声学精度尚未验收 |
| 连续处理 | 持续运行、资源有界、区分快照淘汰与PCM丢失，故障停止/恢复 | 已有二维千帧及CF1A 30.016秒原生摘要；用户“几分钟”观察单列，完整组合长稳未闭合 |
| 双轴指向 | 标定零位/正反/范围、跟随、限位、超时与STOP，并测实际机械响应 | 手动与跟随已有动作观察；当前J3/M15/J14，位置命令不等于有舵机到位反馈，全行程/精度仍需实测 |
| 工程可实现性 | 同候选资源、setup/hold、CDC/RDC、I/O/DRC和约束覆盖 | S2受约束路径裕量为正；缺外部delay与CDC覆盖限制按实际报告保留 |
| PS软件通路 | 真实ARM/PYNQ运行、共享库/采集接合、调度和停止恢复 | 已有ARM与板端运行；PC离线测试不能替代目标板长稳 |
| 声纹许可 | 本人/他人独立评分与门限；过线从完成时刷新TTL，到期无新通过则失效；故障/会话停止 | 已有CP1/VF1及串行对照；低分/静音不提前清TTL，但音量/方向独立限制动作；不承诺多人身份方向绑定 |
| 触屏交互 | 显示、触摸、模式/轴/目标/参数选择、启停，验证与声纹/动作同会话工作 | S2基础显示/触摸已有板测，S3面板已有检查；完整联合操作和长稳需对应证据 |
| 可复现与交付 | 匹配的BD/PS/IP、源码、bit/HWH、环境与可执行说明 | 已有交接和SD包；后续跟随候选变化维护，不把打包当整机验收 |
| 比赛材料 | 对应实际候选的报告、照片/视频、授权和真实AI协作材料 | B补充资料已归档；缺失实物材料不能用历史软件结果替代 |

不新增未经确认的角度误差阈值、长稳时长或资源余量百分比。已撤销的功能及旧STM32跨板任务不列为当前完成条件；历史成绩、失败记录和贡献归属原样保留。四份比赛成品按[范围规则](final-report-scope.md)更新。
