## 结论与接续

此组样本的数据传输、录音保存及时间关联通过；讲话和背景有明显能量/频谱差异。默认门限与筛选在本样本上能挡住背景、输出集中的讲话方向，现阶段没有据此放宽门限或修改RTL的依据。
