# 迭代过程与实验结果

## 2026-10-29资料同步（不新增实验批次）

A已归档B完整补充原件；W16手动可转、纯声音跟随动作及整板重启失败分别按原记录引用。当前主方案为PL+PS，A全面接管。详见[当前说明](07-b-contribution-and-gaps-20261029.md)和[结论边界](05-scope-and-followup.md)。本次未运行新测试，不新增E编号或绘图指标，不累加既有测试数。

## 可以画哪些图

使用[metrics.csv](metrics.csv)，按comparison_group分图，保留scope与timing_boundary：

1. 核心模型/线程柱状图：ECAPA、CAM++单/双线程，源语音同为3.104秒，注明不同模型特征帧数及每组仅2次。
2. CAM++候选柱状图：fp32-opt、fp32-fixed、int8-head，均308帧/两线程。图优化/量化收益只是该小样本观察，不是普遍加速比例。
3. opt1前端与声纹分成两个面板：只前端显著下降，声纹变化约0.16%不作为显著收益。VAD和Mel已经包含在前端内，不能再叠加到总耗时上。
4. 同一输入CPU对照：独立前、前端并发、独立后，分别6次；保留第一次和离群值，不选择性剔除。
5. epoch26三窗时间/分数表：前两次3.806607/3.842636秒过期，最后1.755893秒但分数不足且发布已跨采集结束；不要把最后一次当持续并发速度。

图表不能把主机、QEMU与板端混在一起；不能把吞吐比当首个身份响应时间。首次响应还包括收集窗口、排队与判决。

## 必要失败事实

- [全网INT8未采用](records/E11/pc-evaluation.json)：历史真实块最低余弦0.98994076低于预设0.99数值条件。部分INT8也不等于无精度损失。
- epoch23小声录音被用户排除正常音量身份评价；只保留诊断用途。epoch22换人时刻不明，不做逐窗身份正确率统计。
- 原始target/non_target分数不是有效身份；结果过期或会话失败后不可用于控制。
- sha清单CRLF、Python环境、overlay路径和logs权限属于部署问题，不能当模型识别错误。
- FPR-R1发现“总Run数相符但某Run无节点仍COMPLETE”的统计漏洞；修正逐Run节点覆盖与归属，修复一次，见[E08复核](records/E08/review.json)。这属于测量质量改进，不是模型提速。

第三方模型研究及全量历史技术说明可追溯[v3公开源码包](https://github.com/TophBeifong1744/SoundSight/releases/tag/speaker-b-handoff-20261026-v3)，本目录只选写报告需要强调的材料。更晚进度见[后续与限制](05-scope-and-followup.md)。
