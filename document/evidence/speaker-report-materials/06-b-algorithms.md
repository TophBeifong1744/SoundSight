# B的算法工作与比赛源码入口

本页整理B已交付的算法和实现，不改变A当前总工程。声纹模型原理归CAM++/Silero原作者；本项目贡献是适配、计算布局/数据路径优化、测量与工程接合。三维部分基于四麦时差的远场方向模型，不是声源三维坐标/距离定位。

## 一、声纹：做过哪些优化，效果是什么

| 工作 | 修改位置/办法 | 实测效果与可引用范围 |
|---|---|---|
| P02目标登记与配置 | 原ARM后端登记，保持不同目标配置隔离、score-only | 开发录音有分数间隔，未完成独立门限/准确率验收；[E19](records/E19/README.md) |
| RX4采集CPU | 全通道S24符号扩展改字节校验；空轮询4读减1读；验证布局后的uint32标量读 | 3000包RAM校验CPU 7.608935→0.326382秒，约降95.71%；不是端到端；[E12](records/E12/README.md)、S07 |
| MP1 | 开启ORT memory pattern，保留同编译器基线 | 一秒窗墙时约降0.66%，未见实用收益；[E13](records/E13/README.md) |
| FS1 / CC1 | FS1只固定98帧；CC1尝试改写CAM上下文 | FS1数值一致但无明显加速；CC1在ORT1.17.3数值失败；[E14](records/E14/README.md) |
| CP1 | 55处1×1投影改常量右矩阵MatMul；52处CAM gate采用tile8，原权重值保留 | ARM独立约降14.81%，节拍并发约降15.84%，向量/分数逐位一致；[E15](records/E15/README.md)、S08 |
| VF1 / CP2 | VF1展开固定16kHz及形状确定的7个VAD分支，循环状态连续；CP2尝试局部卷积改写 | VF1 ARM整体前端约降5.14%；同轮CP1+VF1比原组合快18.12%、比CP1再快2.01%；CP2数值失败；[E16](records/E16/README.md)、S09/S10 |

CP1/VF1加速没有通过改变窗口、降低识别门限或延长有效期得到。CP1仅支持一秒98×80特征；VF1只支持当前16kHz输入/状态形状。A后来增加的许可保持策略是另一项系统行为，不能当作推理加速。

原RX4实麦约3秒仍超过当时2秒源窗期限。1.296秒为最新组合的离线前端并发推理，不是从发声到动作的总延迟。A联合实现软件测试见[E10](records/E10/validation.json)，仍不替代真实并发、身份门限和人物跟随验收。

完整声纹运行包由A/B私下交接；公开目录按规则提供[关键源码摘录](03-code-highlights.md)、文件/候选哈希和公开证据。S07～S10是新候选实现片段，不能误写成原v3已有代码；完整原v3公开源码入口保留在[来源表](source-map.json)。不上传私人录音、登记模板、特征数组或模型权重。

## 二、正四面体三维定位

B将原C三维算法适配到独立Linux接口，集中在`software/tetra3d/`，保留二维调用及公共硬件协议。四个麦克风产生六对时差；按源码的通道/lag符号构造几何方程 `A u ≈ τ`，求方向向量u，再输出方位角和俯仰角。默认几何为声孔中心边长40mm的标称正四面体，48kHz、声速343m/s；尚不把标称坐标当作实物测量。

实现包括几何秩/条件数与时间差窗口检查、逐对质量与插值、残差/模长拒绝、上下极点方位无效标志、独立C共享库桥及Python ctypes/JSONL回放。`ux/uy/uz`是拟合方向，不是以米为单位的位置；不输出距离。

[E17](records/E17/README.md)记录154组实际C/Python数值对照、17类非法输入、15组几何、4类CLI及原C回归。PC调用中位11微秒含Python/ctypes/几何/解算，不是Cortex-A9速度。合成角度一致性不等于房间反射条件下的声学精度。

## 三、三维定向拾音DAS

三维DAS使用与求解器相同的几何和方向。相对CH0计算每通道延时 `d_i = fs/c · dot(r_i-r_0,u)`，量化为Q12；四路做线性分数延时后等权平均。包括流式块处理、方向切换淡变、到期退回校准后的单麦、固定8点延迟和尾部输出。

它是延时求和波束形成，不是MVDR、回声消除、混响消除或说话人分离。线性插值存在高频幅频误差，相近方向/低频干扰不能保证消除。DAS模块已与实际C求解器在PC合成链路接合，但不能据此说已接入PYNQ实麦或声纹输入。

## 四、六项兼容优化与模块接合

| 项目 | B实现内容 | 行为与边界 |
|---|---|---|
| 空间方向稳定 | 单位向量筛选、平滑、死区、有界HOLD、候选重捕获 | 独立于原求解结果；HOLD不刷新旧观测期限 |
| 可选质量加权 | 按相关峰质量给有界权重，默认关闭 | 所有合格对的未加权残差仍保留；不靠丢掉坏对隐藏问题 |
| DAS计算/分配 | 17槽环缓冲、预分配输出、关闭不使用的逐点trace | 默认音频和3347989逐点一致，需配套更新两层DAS |
| 通道校准 | 定位与DAS共用延迟约定，DAS支持增益校准 | 校准值需实测；默认零延迟/单位增益不能称已标定 |
| 几何与有效对缓存 | 按实例缓存几何和64种有效对组合，版本化选项 | 旧ABI/默认结果保持；不同实例不共享错误状态 |
| 纯软件双轴 | 安装旋转、极点迟滞、限速、范围、到期处理 | 只算软件设定值，初始姿态/机构配置显式，默认禁止输出；不是A的真实PWM提交 |

`TetraPipeline`进一步统一求解→方向滤波→可选DAS/软件双轴及校准来源。传入真实源采样时标，过旧/故障/BIST/STOP撤销旧方向；不补造PCM或采样关联。按当时用户要求只交可导入模块，没有新增在线运行入口。

[E18](records/E18/README.md)保存PC证据：86项不同Python测试（后续重复执行不重复累计）；PC DAS 48000点中位0.176659→0.113945秒，约快35.50%；8192点块tracemalloc峰值2616168→99820字节，约降96.18%。这是块分配，不是进程内存。合成方向RMS 2.722807°→0.898019°；单个低质量对案例误差4.049°→1.747°，均非实物普遍收益。

## 六、报告归属与未完成项

B材料覆盖早期三维算法迁移/DAS及软件优化、声纹目标配置/计算优化/诊断板测。A的RTL、连续PCM硬件接口、当前三维采集与双轴提交、联合许可策略等沿用既有A材料，不归入B算法优化数字。原研究模型不归属任一组原创。

后续仍需实际几何/通道/延迟增益标定、真实连续PCM与定位时标关联、ARM负载与实麦增强效果、目标识别阈值及独立数据、声纹结果与正确声源角度的关联、机械闭环。可写“模块/数值验证完成”，不能写“整机人物跟随已经完成”。
