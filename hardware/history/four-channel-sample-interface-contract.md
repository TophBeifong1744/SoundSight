# 四路同步样本接口契约

版本：`draft-0.1`

状态：M0 草案，物理采集器件和样本格式冻结后升级为 `frozen-1.0`。2026-09-08 起，离线读取器/算法与 TB 可先按[最小数据接口 ss-data-draft-0.2](../document/minimal-data-interface.md)开发，暂定值显式版本化；本文件未全冻结不阻塞独立工程或软件开发，仅约束真实接口接入及最终合同验收。

## 1. 目的与边界

本契约定义 `channel_align` 向后级交付的统一四通道样本组，使 PDM、TDM/I2S 或并行 ADC 等不同采集方案在进入处理链前收敛到同一种语义。

它不定义尚未确认的麦克风/ADC 引脚、外设时钟频率、抽取滤波器或 Codec 初始化；这些内容必须由真实器件资料和板上测量补齐。

## 2. 核心不变量

1. 一次有效传输包含同一采样序号的四个通道，不允许四路独立握手。
2. 通道顺序固定为 `{mic3, mic2, mic1, mic0}`，其中通道编号必须与阵列坐标表一一对应。
3. 物理采集不能被下游反压暂停；采集边界必须使用 FIFO 或明确的停止抓取策略。
4. 任何丢样、重复、乱序、溢出或重新锁定都必须可观察，不能静默发生。
5. 跨时钟域只能通过经过验证的异步 FIFO 或握手快照，不允许直接同步多位样本总线。

## 3. 规范化流接口

以下是接口语义，不是待立即实现的 RTL 端口文件。

| 信号 | 方向 | 宽度 | 语义 | 冻结状态 |
|---|---|---:|---|---|
| `clk` | 输入 | 1 | 规范化音频流所在时钟域 | 频率待冻结 |
| `rst_n` | 输入 | 1 | 本时钟域低有效复位；异步断言、同步释放 | 策略候选 |
| `sample_valid` | 输入 | 1 | `sample_bundle` 与伴随元数据当前有效 | 语义已定 |
| `sample_ready` | 输出 | 1 | 下游可接收当前样本组 | 语义已定 |
| `sample_bundle` | 输入 | `4*W_SAMPLE` | `{mic3, mic2, mic1, mic0}` | 排列已定，位宽待冻结 |
| `sample_id` | 输入 | `W_SAMPLE_ID` | 从一次明确的采集启动起单调递增，每个样本组加 1 | 位宽待冻结 |
| `config_version` | 输入 | `W_CFG_VER` | 产生该样本时生效的硬件/接口配置版本 | 位宽待冻结 |
| `stream_error` | 输入 | 1 | 当前样本或此前链路出现完整性错误 | 编码待冻结 |

一次传输只在 `sample_valid && sample_ready` 为真时发生。若 `sample_valid=1` 且 `sample_ready=0`，发送端必须保持样本组、`sample_id` 和伴随元数据不变。

## 4. 连续采集与反压边界

```text
物理麦克风/ADC
  -> 不可暂停的采集与通道成组
  -> 非阻塞采集 FIFO
  -> 规范化 valid/ready 流
  -> 处理链与原始录音抓取
```

下游反压不会传播到物理输入。FIFO 容量不足时，系统必须执行已冻结的失败策略：

- 继续实时处理但终止本次录音；或
- 继续写入后续数据，并在元数据中标记丢失区间。

无论采用哪一种，至少保留 `overflow_sticky`、`overflow_count`、`drop_count` 和出错前后的 `sample_id`。M1 前必须从两种策略中选定一种。

## 5. 样本数值格式

| 字段 | 冻结值 |
|---|---|
| 目标采样率 | 候选 `48 kHz`，待采集器件确认 |
| `W_SAMPLE` | 待冻结 |
| 有效位宽 | 待冻结 |
| 编码 | 候选二进制补码有符号整数 |
| 小数位 | 待冻结；原始 ADC 码可定义为 0 |
| 满量程定义 | 待冻结 |
| 扩位规则 | 待冻结，符号扩展不得改变物理增益 |
| 舍入规则 | 采集规范化阶段原则上不舍入；若必须舍入需给出算法和误差 |
| 饱和/溢出 | 待冻结，禁止无标志回绕 |

`48 kHz` 和 24 bit 目前是预算基线，不是由硬件证据确认的最终格式。

## 7. 时钟域与复位

| 时钟域 | 来源 | 频率 | 与采样的关系 | 当前状态 |
|---|---|---:|---|---|
| `clk_acq` | 麦克风/ADC 时钟或同步派生 | 待填 | 承载物理采集、解串/抽取和通道成组 | 待冻结 |
| `clk_pl` | PS FCLK 或板级 50 MHz 经 MMCM/PLL | 待填 | 承载预处理、定位和波束形成 | 待冻结 |
| `clk_axi` | PS FCLK | 待填 | 承载 DMA、寄存器和 DDR 通路 | 待冻结 |
| `clk_audio_out` | Codec/DAC 时钟 | 待填 | 承载增强音频输出 | 待冻结 |

每个时钟域独立同步释放复位。跨域结构、时钟关系和时序例外必须在专用 XDC 中有可追溯约束；禁止用大范围 false path 掩盖未设计的 CDC。

## 8. 原始录音块必须携带的元数据

- 格式版本、采样率、有效位宽和存储位宽；
- 通道顺序与阵列几何版本；
- 抓取点和首个 `sample_id`；
- 样本组数量、块序号和时间戳；
- `config_version`；
- FIFO/DMA/环形缓冲溢出及丢失计数；
- 实验编号、声源角度、距离、房间和设备状态。

文件长度、样本组数量、块序号和 `sample_id` 增量必须能互相校验。

## 9. M1 接口验收用例

| 用例 | 输入/操作 | 通过条件 |
|---|---|---|
| 复位重启 | 在空闲和连续采集中分别复位 | 重新起点明确，不输出伪有效样本 |
| 四路标号 | 四通道注入可区分固定码型 | 通道映射和 packed 顺序完全正确 |
| 连续计数 | 长时间连续输入 | `sample_id` 无跳变、重复或倒退 |
| 间断/重锁定 | 暂停外设或制造失锁 | 错误可观察，恢复边界有明确标记 |
| 下游反压 | 随机拉低 `sample_ready` | FIFO 内数据保持；超容量时按冻结策略报错 |
| 边界样本 | 输入最大正值、最小负值、零和交替码 | 符号、位宽和扩位正确，无静默回绕 |
| 跨域压力 | 改变读写相位并长时间运行 | 无乱序、重复或亚稳态可见错误 |
| 原始导出 | 抓取已知长度四路序列 | 文件可重复解析，元数据和样本数互相一致 |
