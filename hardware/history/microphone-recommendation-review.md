# 麦克风建议复核与当前选定路线

状态（2026-09-07）：用户已选定IM73D122V01／PDM并要求沿用；模块、板级连接和四通道实测尚未通过。本轮不重新选型或更换接口。

## 1. 结论

当前沿用IM73D122V01／PDM；INMP441仅保留为历史I²S备用讨论，不是当前重新选型要求。两者属于不同接口路线，不能互换接收逻辑，也不能依据用户选定或芯片参数直接判定“所有硬性指标合格、可直连开发板”。

hsc119 的建议中，IM73D122V01 的高信噪比、较小灵敏度公差和 PDM 接口判断基本成立；INMP441 被误写为 PDM，其灵敏度公差也被误写为 ±1 dB。商品将 INMP441 标为 I²S 是正确的，不能据此排除商品。

本文的 60/64 dBA、灵敏度公差等门槛来自项目[采购指标](procurement-specifications.md)，不是竞赛直接规定的麦克风参数。典型参数不等于每只器件的保证下限，资料复核不等于板测通过。

## 3. 四路接口路线

### IM73D122V01：PDM 路线

- 四只共用 CLOCK；每两只 LR 取不同电平，可交替驱动同一 DATA，总计两根 DATA。模块必须确实引出 LR，且未加入妨碍共享总线的电路。
- FPGA 接收 PDM 位流，对四路执行一致的低通、抽取和启动清零，形成同一采样序号的四通道 PCM。
- 3.072 MHz 除以 64 可得到 48 kHz，但必须包含正确的抽取滤波，不能每隔 64 个位简单取一个值。
- 手册给出的 3.072 MHz 所在工作区间为 2.9～3.3 MHz；不能把此前项目的“1～3.25 MHz”示意范围当成芯片连续支持范围。

### INMP441：历史I²S备选说明，当前不实施

- 四只共用 SCK 和 WS；每两只分别选左、右时隙，共用一根 SD，四只使用两根 SD。须按模块原理图确认共享数据线条件。
- 在 48 kHz、每立体声帧 64 个位时钟条件下，SCK 为 3.072 MHz，WS 为 48 kHz。
- FPGA 解析 I²S 的位序、相对 WS 的数据延迟、24 bit 有效字和左右槽位，再组成四通道样本。
- 相比 PDM 路线，接收端省去 PDM 抽取，但仍需处理通道映射、对齐和固定差异标定。

当前PDM路线必须分别证明：共享采样时基不存在相对漂移；通道增益、相位和延迟差可重复测量并校准。共用时钟本身不能代替这两项实测。上述I²S说明仅保留接口纠错依据。

## 4. IM73D122V01 的实施注意事项

1. 启动等待从有效供电和 CLOCK 都已施加后开始计时。手册列出达到 ±0.5 dB 启动精度需 20 ms，±0.2 dB 需 50 ms；应持续提供时钟并丢弃启动数据，随后还要等待 FPGA 抽取滤波器稳定。
2. 3.072 MHz 下时钟占空比要求为 48%～52%，应检查实际负载下的波形。
3. 手册要求 VDD 附近放置 1 μF 旁路电容；立体声应用图另建议近端 100 nF。选模块时核对实际去耦布局。
4. DATA 负载电容上限为 200 pF，但手册的数据有效时间另有测试负载条件；不能仅满足电容上限就宣称时序满足。
5. 7 μs 是 1 kHz 条件下的器件群延迟，不能当成整个 PDM 接收链的延迟；FPGA 滤波延迟必须单独计入。

## 5. 选型决策与采购前清单

用户已选IM73D122V01，其原有推荐依据是更低的典型自噪声和更紧的灵敏度公差；仍需获得资料完整、焊接可靠、声孔正确的模块，并完成FPGA抽取滤波验证。

历史讨论中的INMP441接收前端相对简单，但信噪比余量较小、灵敏度公差较大，且“PDM、±1 dB”的原建议错误；本轮不因此换型或采购它。

- [ ] 明确购买的是裸芯片还是已焊接模块；裸芯片需要合适的 PCB、声孔及贴装条件。
- [ ] 取得模块正反面照片、芯片丝印、原理图和准确型号，核对稳压、电平转换、去耦及声孔位置。
- [ ] 确认所选IM73D122V01模块的CLOCK/DATA/LR能按V1四路PDM拓扑连接。
- [ ] 将模块实际供电、输出电平和时序与领航者所选 Bank 的 VIO、输入阈值、管脚逐项对应，尚未确认前不声称可直连。
- [ ] 确定接收边沿、启动丢弃区间、通道顺序、采样格式、错误计数和原始录音导出方式。
- [ ] 同源录音并重复冷启动/复位，分别检查相对漂移、固定延迟、增益、相位和通道映射。
- [ ] 在同一组四通道录音上比较固定单麦、手动真实方向波束、自动方向波束，确认实际收益。

V1原有“同型号、同批次5只，4只使用、1只备用”仅是历史数量建议，备件不算第五个同步通道；实际采购需按盘点和授权执行。同批次不能替代逐通道标定。V2当前只做六麦软件预研，未准入不加购；型号路线已由用户选定，不等于具体模块、引脚与板级接口已验收。

[六麦软件报告](../document/six-mic-acoustic-software-review.md)已有2700帧、21项自检及独立复跑一致的证据，但带内0 dB有效率47%、等强竞争场景26%，完整3D-G0未通过。该理想麦模型未包含具体模块/PDM抽取链，不能替代本节实测；六麦A/B/C是同组六路数据的单麦参考/手动真实指向/自动指向，不新增四麦模拟。整理后的入口见[独立材料包](../deliverables/six-mic-acoustic-review-v1/README.md)。
