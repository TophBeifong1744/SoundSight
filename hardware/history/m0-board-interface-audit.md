## 1. 证据等级

| 等级 | 含义 | 当前可做的事 |
|---|---|---|
| A：实物确认 | 丝印、测量、原理图和器件资料一致 | 可进入正式接口表和 SoundSight 专用 XDC |
| B：资料候选 | 厂商规格书、原理图、IO 表和 XDC 互相一致，但尚未核对实物 | 只可用于候选设计和现场核对清单 |
| C：待查 | 只有口头描述、单一来源或仍有冲突 | 不得用于实现或采购冻结 |

当前下表中的板卡系列、底板版本和 FPGA 器件族已经提升为 **A 级实物确认**；速度等级、Codec 和具体接口参数仍为 B/C 级，不因同一张照片中出现板卡而自动升级。

## 4. 不能直接使用厂商 XDC 的原因

厂商 XDC 是多个示例工程的合集，不是 SoundSight 的约束文件：

1. 同名 UART 端口在不同示例段落中映射到不同引脚。
2. LCD 与 HDMI 示例复用了 R19、P20 等引脚。
3. 摄像头、以太网、音频等互斥或无关外设同时存在。
4. 文件没有表达 SoundSight 的四路采集接口和外部时序。

因此，正式约束只能在实物和采集器件确认后新建专用 XDC，并只保留实际启用的端口、时钟、IOSTANDARD 与输入/输出延迟。仓库正式规范化时使用 `project/sdc/`；当前实际约束仍在外部原生工程，本次目录迁移不创建或改动约束。

## 5. 四路同步采集仍缺少的事实

| 字段 | 必须获得的值 | 当前状态 |
|---|---|---|
| 采集器件 | 厂商、完整型号、模块版本、数据手册 | 待提供 |
| 通道数 | 单器件/多器件如何组成 4 路 | 待提供 |
| 物理接口 | PDM、TDM/I2S、并行 ADC 或其他 | 待确认 |
| 共享时钟 | 时钟源、主从关系、频率、占空比、采样边沿 | 待确认 |
| 帧格式 | 通道槽位、字长、有效位、符号、对齐方式 | 待确认 |
| IO 电平 | 外设 VIO、是否 5 V 容忍、是否需电平转换 | 待测/待查 |
| PL 引脚 | 连接器针脚、FPGA 管脚、Bank、冲突外设 | 待选取 |
| 固定延迟 | 四通道链路是否同构、怎样测量和校准 | 待设计 |
| 输出链路 | ES8388、外接 DAC 或仅先导出文件 | 待决定 |
| 长录音导出 | DDR 缓冲后走 SD 或网络 | 待决定 |

板载 ES8388 不等于四路同步 ADC。只有在实际器件证明具备四个同步输入通道、PL 可取得各通道原始样本且时序可验证时，才能把它纳入采集方案。

## 8. 当前结论

板卡系列、底板 `V3.9`、`XC7Z020` 器件族和 Vivado `2025.2` 已确认，降低了板卡身份与工具版本风险。M0 仍被“完整 FPGA part/速度等级、Codec、ADC/DAC/麦克风型号、PYNQ 准入、时钟/电平/引脚和四路接口时序”阻塞。在这些信息补齐前，不创建正式 XDC，不实现依赖猜测接口的 `mic_phy_rx`，不进入 GCC-PHAT/DOA RTL。
