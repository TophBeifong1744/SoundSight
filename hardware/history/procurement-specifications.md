## 1. 已知条件与采购原则

当前照片能够确认：

- 正点原子领航者 `ATK-DF7010P_7020P` 系列；
- 底板丝印 `ATK-DF7010/7020P V3.9`；
- 核心板正面丝印 `CF7010B/7020B`；
- 芯片属于 Zynq `XC7Z020` 器件族。

照片尚不能确认完整 Vivado part、封装与速度等级、核心板背面版本、板载 Codec 型号，也没有证明外接 ADC、DAC、麦克风、时钟、电平、引脚、DDR/SD/网络或 PYNQ 已可用。现有 ADC/DAC 的型号、通道数、接口和输出能力仍待提供。

V1真正需要的是“四路严格同步的原始音频”，不是四个能分别采到声音的通道，当前采集路线为IM73D122V01／PDM。现有ADC/DAC只有在型号、接口、时钟和通道能力满足对应用途后才能计入可用硬件；盘点现有ADC不代表重开模拟麦选型。

采购遵循以下顺序：

1. 先证明四路共用采样时基，通道之间不存在独立时钟造成的相对漂移；
2. 再单独测量并校准通道固定增益、相位和延迟差，同时验证阵列结构；
3. 先在 M5 用真实录音证明定位与电子波束收益；只有存在明确朝向载荷时，才采购或集成转台；
4. 显示屏、无线通信、滑环等不影响核心闭环的器件暂缓购买。

### 1.1 赛题器件范围与实板验收约束

依据 AMD《2026 FPGA 赛道选题指南》3.3.1.1 和 3.3.3.2，第三赛道初级组可使用 AMD 7 Series FPGA、Zynq-7000 SoC、UltraScale 或 UltraScale+ 系列器件。当前照片确认的 `XC7Z020` 器件族属于允许的 Zynq-7000 范围，但这只证明“器件族不越界”，不能证明具体型号声明、工程构建或板上运行已经通过。

赛题还要求两组均声明具体器件型号，选择团队真实可获得且能完成板级验证的器件，作品必须在板上跑通并保存实测输出。因此硬件验收至少分为以下四级：

| 层级 | 当前状态 | 升级条件 |
|---|---|---|
| 器件系列合规 | 通过 | 官方指南允许 Zynq-7000，照片可读 `XC7Z020` |
| 实物身份 | 部分通过 | 板卡系列和底板 V3.9 已有照片；仍须补齐完整 Vivado part/速度等级与核心板版本对应关系 |
| 板级功能 | 未通过 | 目标 part 的 Vivado 2025.2 工程在该实板下载运行，时钟、复位、DDR、接口和电平分别有测量记录 |
| 系统实测输出 | 未通过 | 四路真实采集、原始录音导出、状态/错误计数和增强音频均留下可复现输出及输入条件 |

实物全景中出现 J3/J4、SD 卡槽、RJ45、音频插座或其他连接器，只能形成“存在该外观/丝印”的照片证据。没有原理图逐项对应、供电与 VIO 测量、启动/驱动记录和数据传输结果时，不得写成接口电气可用、软件可用或 PYNQ 兼容。

## 2. 当前采集路线与核验指标

### 2.1 已选路线：四只IM73D122V01数字MEMS麦克风

用户已选IM73D122V01／PDM，本轮不改型号或转为TDM/I²S。数字路线省去外部模拟前置放大器，但共享时基、PDM抽取和通道差异仍需实测。以下门槛用于核实所选路线，具体器件参数及原建议纠错见[麦克风评审](microphone-recommendation-review.md)。

| 指标 | 最低要求 | 推荐目标 | 淘汰条件 |
|---|---:|---:|---|
| 数量 | V1有源4只 | 历史4用1备建议，按实际盘点与授权确认 | 少于4路有效同步输入 |
| 指向性 | 全向 | 四只声学结构完全一致 | 混用不同指向性 |
| 输出 | 原始PDM | 可核实LR选择和数据线共享条件 | 仅输出USB音频或隐藏自动处理的数据 |
| 同步方式 | 四路共用同一个采样时钟 | 一个时钟输出驱动全部麦克风 | 每只麦克风自由运行、无法共用时钟 |
| 固定通道差异 | 增益、相位和延迟可测且多次启动后稳定 | 数据手册说明群延迟，支持同源录音标定 | 用“可校准”掩盖独立时钟漂移，或延迟随启动随机变化 |
| 供电与 IO | 与 3.3 V LVCMOS 兼容 | 1.8～3.3 V 供电，3.3 V IO | 5 V 数据直接接入 PL |
| 信噪比 | ≥60 dBA | ≥64 dBA | 未给出 SNR 或明显低于 60 dBA |
| 灵敏度偏差 | ≤±3 dB | ≤±1 dB | 无公差说明且无法逐通道标定 |
| 频率范围 | 覆盖 200 Hz～4 kHz | 覆盖 100 Hz～8 kHz | 只有声强检测，不能还原语音波形 |
| PDM 时钟 | 工作区间覆盖3.072 MHz | 按所选器件手册核验2.9～3.3 MHz工作区及占空比；不沿用旧1～3.25 MHz泛化范围 | 实际时钟频率/波形不满足手册 |
| 抽取后PCM | 48 kHz | 3.072 MHz经一致低通及64倍抽取，位宽/标度由合同核实 | 简单丢位代替滤波，或通道抽取相位不一致 |
| 自动处理 | 无 | 无 AGC、降噪、AEC、波束形成 | 内置不可关闭的 AGC/降噪/回声消除 |
| 引脚 | VDD、GND、CLK、DATA | 额外具有 L/R、SEL 或时隙选择 | 不公开时序或无法取得原始数据 |
| 资料 | 有完整数据手册与时序图 | 有原理图、PCB 尺寸和声孔说明 | 只有商品宣传页 |

PDM 接口的目标连接形式：

```text
ZYNQ PL PDM_CLK  -> 4 个麦克风共用 CLK
ZYNQ PL PDM_D01 <- 麦克风 0/1，共用数据线，以 SEL 区分上升沿/下降沿
ZYNQ PL PDM_D23 <- 麦克风 2/3，共用数据线，以 SEL 区分上升沿/下降沿
3.3 V / GND      -> 四路共用低噪声供电与参考地
```

接线前必须按器件手册和实际模块原理图确认两麦共享DATA的条件；未证明共享时按1个CLK＋4个DATA核查同一PDM路线的资源，不自行换型或购买模块。

### 2.2 历史比较依据：模拟麦克风＋同步ADC（当前不采用）

以下保留历史模拟前端/ADC技术门槛以便理解取舍，不是当前采购或实现清单。当前沿用IM73D122V01／PDM；即使现有ADC满足下表，也不能自动切换路线，重新决策须由用户另行授权。

#### 模拟麦克风及前置放大器

| 指标 | 最低要求 | 推荐目标 | 淘汰条件 |
|---|---:|---:|---|
| 麦克风 | 4 只相同全向麦克风 | 同型号、同批次、可测灵敏度 | 混用不同模块 |
| 前置增益 | 四路固定且一致 | 增益误差 ≤0.5 dB | 带不可关闭的自动增益 AGC |
| 带宽 | 100 Hz～8 kHz | 低频截止一致、相位响应可查 | 只有包络/比较器输出 |
| 输出 | 能匹配 ADC 输入范围 | 差分输出优先 | 输出幅度、偏置和 ADC 不兼容 |
| 噪声 | 不明显限制 ≥60 dBA 的系统 SNR | 低噪声运放、独立去耦 | 电机启动时出现明显底噪或削顶 |

#### ADC 必须满足的指标

| 指标 | 最低要求 | 推荐目标 | 淘汰条件 |
|---|---:|---:|---|
| 通道数 | 4 路 | 4 路或以上 | 单通道/双通道且无法严格同步扩展 |
| 采样时基 | 四通道由同一采样时钟或同一帧时钟定义 | 单颗多通道同步音频 ADC，或共用 MCLK/BCLK/FS 的确定性系统 | 四块模块使用四个独立晶振，或通道间存在长期相对漂移 |
| 采样率 | 48 kS/s/通道 | 48～96 kS/s/通道可配置 | 每路采样率不一致 |
| 有效分辨率 | ≥16 bit | 24 bit 音频数据接口 | 只有高标称位数但有效位数不足且无指标 |
| 数字接口 | 可直接进入 PL | TDM/I²S，3.3 V IO | USB、仅能进入 PC，或隐藏内部缓冲时延 |
| 时钟 | MCLK/BCLK/FS 关系明确 | FPGA 提供或锁定到同一主时钟 | 时钟来源、相位或复位行为不公开 |
| 固定通道差异 | 通道增益、相位和采样时隙差固定且可测 | 有数据手册给出的群延迟/孔径时延，并可做同源标定 | 通道延迟随启动或配置变化且不可测 |
| 模拟输入 | 与前置放大器幅度/偏置兼容 | 差分输入、输入范围和抗混叠明确 | 需要超出当前能力的高压模拟前端 |

高速 ADC 不等于适合音频阵列。如果现有 ADC 是单通道高速采样模块，即使采样率远高于 48 kS/s，也不能自动满足四路同步要求。

### 2.3 同步证据与固定差异标定必须分开

“同步”回答四路样本是否由同一时间基准产生，重点排除独立晶振、异步重采样和不可控缓冲造成的相对漂移；“固定差异标定”回答同一采样时基下，各通道是否仍存在稳定的增益、相位、群延迟或时隙偏差。二者都必须通过，但不能互相替代。

| 验证对象 | 必须取得的证据 | 通过判据 |
|---|---|---|
| 同一采样时基 | 数据手册/原理图时钟树；示波器或逻辑分析仪的 CLK、MCLK/BCLK/FS、帧边界记录 | 四路没有独立自由运行时钟；采样序号和帧边界一一对应，无长期相对漂移 |
| 固定差异 | 四路同源原始录音；多次断电、复位后的互相关、增益和相位结果 | 差异可重复并能写入校准参数；不得出现启动后随机整数采样跳变 |
| 通道映射 | 分别靠近 MIC0～MIC3 的标识录音或逐通道电注入 | 物理声孔、数据槽位和文件通道始终一致 |

若候选系统只能证明“共用一个晶振”，但无法证明各通道帧边界和启动相位确定，仍不能冻结；同样，固定延迟可校准也不能挽救独立时钟造成的随时间漂移。

## 3. 麦克风阵列结构指标

首版采用水平二维正方形阵列，不采用直线阵列。直线阵列难以独立判断二维方向，并容易出现前后模糊。

| 指标 | 最低要求 | 推荐目标 |
|---|---:|---:|
| 阵元数量 | 4 | 4 |
| 阵列形状 | 水平二维非共线 | 正方形四角 |
| 相邻中心距 | 采用C转接板实际布局 | 40 mm仅是历史理论参考；不以35～50 mm可调模板要求返工 |
| 尺寸误差 | ≤1 mm | ≤0.5 mm |
| 高度误差 | ≤1 mm | 四个声孔同一平面 |
| 安装方向 | 四只一致 | 声孔方向完全相同且无遮挡 |
| 结构 | 刚性固定 | PCB、亚克力板或 3D 打印支架 |
| 坐标标识 | 有明确编号和正前方 | 标出 MIC0～MIC3、X/Y 轴和 0°方向 |

40 mm 相邻间距在 48 kHz 下的最大相邻时延约为：

$$
\frac{0.04}{343}\times 48000 \approx 5.6\text{ 个采样点}
$$

该间距只是语音频段、角度分辨能力、空间混叠和机械尺寸之间的首版测试点。40 mm 边长的对角线最大传播时差约为 7.9 个采样点；单条边基线在正侧向附近，一个采样点约对应 10.3°，5°变化只有约 0.49 个采样点，因此最终 5°目标不能依赖整数峰值。理想模型还显示其对低频相干干扰的方向选择能力有限，因此要按[声学性能验证计划](../document/acoustic-validation-plan.md)如实记录实际布局和声学收益；既有波束图可复用，不新增四麦声学模拟、不强制已选C板改成可调孔位。

阵列“采集带宽”和“用于定位的有效频带”必须分别记录。40 mm 间距按半波长准则对应的保守无空间混叠频率约为 4.29 kHz；麦克风能够采到 8 kHz，不代表 8 kHz 都应进入 DOA 估计。

### 4.1 原始录音导出所需硬件条件

四路原始录音是阵列间距、固定差异和 A/B/C 声学收益判断的共同输入，导出能力属于采集方案的冻结条件，不是事后附加功能。

四路、48 kHz、24 bit 的净载荷为 4.608 Mbit/s；若每个样本按 32 bit 对齐，则为 6.144 Mbit/s，均未计协议开销。普通低速 UART 只用于状态、计数器和短小调试数据，不能作为长录音主链路。

候选板级链路至少满足：

```text
四路采集 -> 通道成组 + sample_id/frame_id -> FIFO
         -> 短抓取：BRAM
         -> 长录音：AXI DMA/等效主设备 -> PS DDR -> SD 卡、千兆网或其他已验证高速接口
```

- 必须确认目标底板具有可用的 PS DDR，以及一种能够把长录音完整取出的存储或高速通信接口；具体路径以实际底板原理图和板上实测为准。
- 抓取宽度必须覆盖四通道原始有效位，保留通道顺序、符号格式、采样率、阵列坐标和校准前数据。
- 采样计数、帧号、FIFO 溢出/欠载、丢样和复位状态必须随录音保存；四路不得分别录制后再按软件时间戳拼接。
- 导出或存储端短时变慢时，实时采集链路不能被静默阻塞；缓存不足必须给出黏滞错误标志和累计计数。
- 第一批不默认购买额外采集卡。只有现有底板的 DDR、SD 卡、网口或其他接口经原理图核对和实测后仍无法满足，才按缺口补充导出硬件。

## 5. 自动声源跟踪转台指标

转台不是电子波束形成的替代品。M0 只保留以下接口和安全约束；只有 M5 使用同一组真实录音完成单麦 A、手动真实方向波束 B、自动方向波束 C 的对比并证明声学收益，同时明确摄像头、定向扬声器或其他必须朝向声源的载荷后，才按下列指标筛选和采购机械、电气方案。若转动对象只是对称的四只全向麦克风阵列，且没有需要朝向的载荷，机械旋转不作为采购理由。

### 5.1 执行机构

| 指标 | 最低要求 | 推荐目标 | 淘汰条件 |
|---|---:|---:|---|
| 运动形式 | 水平单轴旋转 | 独立承重轴承 + 电机传动 | 用电机轴直接承受整个设备重量 |
| 有效转角 | ≥270° | 约 ±160°，保留线缆安全区 | 只有很小转角且无法覆盖演示范围 |
| 角速度 | 可调，≥20°/s | 30～60°/s | 速度不可控、启动冲击明显 |
| 定位误差 | ≤3° | ≤1° |
| 重复定位误差 | ≤3° | ≤1° |
| 回程间隙 | ≤3° | ≤1° | 明显松旷导致持续摆动 |
| 驱动方式 | 可由 3.3 V 控制信号驱动 | STEP/DIR 或可读写位置指令 | 必须直接给 PL 输入 5 V 信号 |
| 微步 | ≥1/8 | ≥1/16 | 低速振动和噪声无法接受 |
| 转矩余量 | ≥计算动态需求的 2 倍 | ≥3 倍 | 满载启动易失步 |

水平转台绕竖直轴旋转，重力本身不会直接形成绕轴转矩。应先估算所有转动部件对旋转轴的转动惯量

$$
I\approx\sum_i m_i r_i^2
$$

再按

$$
T_{estimate}=I\alpha+T_{friction}+T_{cable}
$$

估算加速转矩，并乘不少于 3 的安全系数。最终还要计入皮带/齿轮效率和驱动电流限制。应优先减小转动惯量、采用独立承重轴承并让质量靠近旋转轴，而不是单纯购买更大电机。

### 5.2 电机驱动器

| 指标 | 最低要求 | 推荐目标 |
|---|---:|---:|
| 电机类型 | 双极步进电机或带位置反馈的执行器 | 低噪声双极步进方案 |
| 控制接口 | STEP/DIR/ENABLE | STEP/DIR + UART/SPI 状态配置 |
| 逻辑电平 | 明确兼容 3.3 V | 3.3 V 可直接识别 |
| 电流能力 | 连续电流 ≥电机额定相电流 | 留 20%～30% 裕量并可调限流 |
| 细分 | ≥1/16 | 内部插值至更高微步 |
| 保护 | 过流、过温、欠压 | 具有故障状态输出 |
| 声学表现 | 可低速平稳运行 | 静音斩波模式，可配置保持电流 |

### 5.3 位置反馈与限位

| 物料 | 最低指标 | 推荐指标 |
|---|---:|---:|
| 绝对角度编码器 | ≥10 bit/圈 | ≥12 bit/圈，I²C/SPI 或 PWM 输出 |
| 零位传感器 | 1 个 | 非接触霍尔或光电开关 |
| 机械限位 | 左右各 1 个 | 常闭触点，断线也能触发故障 |
| 急停/总使能 | 能切断电机驱动 | 独立于软件的硬件使能 |

编码器分辨率不是最终角度精度。装配偏心、传动间隙、阵列零位和设备正前方的标定误差仍需单独测量。

### 5.4 机械件

- 转台轴承：额定载荷至少为实际载荷的 3 倍；径向间隙小，无明显晃动；
- 传动：优先同步带或低间隙齿轮减速，推荐减速比约 2:1～4:1；
- 底座：能够分别固定开发板、阵列、电机和驱动板，不能让电机振动直接作用于麦克风板；
- 线缆：先限制在约 ±160°，暂不购买滑环；需要连续旋转时再评估滑环的通道数、额定电流和信号完整性；
- 防护：必须有机械止挡，防止软件错误拉扯线缆。

### 5.5 M0 只预留的资源

以下内容是资源预算，不代表现在购买器件或冻结引脚：

- 控制输出：`STEP`、`DIR`、`ENABLE`，以及可选 `RESET/BRAKE`，预留 3～4 路 3.3 V GPIO；
- 安全输入：驱动故障、零位、左限位、右限位，预留 4 路输入并优先支持中断；
- 位置反馈：为 SPI 四线、I²C 两线或 ABZ 三线中的一种保留复用余量，另留 2 路备用 GPIO；
- 电源：独立电机电源入口、硬件总使能、保险/反接保护和驱动端储能位置，不从开发板扩展电源取动力电；
- 机械：转轴尽量经过阵列声学中心，预留中心过线、线缆应力释放、机械止挡和编码器同轴安装基准；
- 坐标：在安装图上同时标出 MIC0～MIC3、阵列 X/Y 轴、设备正前方、旋转正方向、机械零位和编码器零位。

具体 GPIO、Bank、IOSTANDARD 和连接器只有在领航者底板版本、现有外设占用和驱动器电平确认后才能填写。

### 5.6 转动时的声学、时间戳与坐标风险

- 电机断电、上电保持、匀速、加减速和停止后稳定五种状态都要保存四路原始录音，比较噪声谱、削顶、时钟/位错误、DOA 有效率和错误指向比例；只测“静止/转动”不足以定位干扰来源。
- 运动中的结构振动、电磁干扰、线缆摩擦和气流可能成为离麦克风最近且高度相关的声源，因此首版采用“转动 -> 停止 -> 等待稳定 -> 重新定位”，运动帧标为无效或降低置信度。
- 每个 DOA 结果必须携带帧中心的 `sample_id` 或由采样计数派生的时间戳；编码器角度必须映射到同一时间基准，不能仅以 PS 收到结果的时刻代替测量时刻。
- 以 21.3 ms 帧、60°/s 为例，一帧内姿态变化约 1.28°；50 ms 总延迟对应约 3°。在目标定位误差约 1°～5°时，这些量不能忽略。
- 阵列坐标固定在设备坐标系中；世界方向应按帧中心时刻计算：

$$
\theta_{world}(t_f)=\operatorname{wrap}\left(\theta_{encoder}(t_f)+\theta_{DOA,body}(t_f)+\theta_{zero}\right)
$$

其中必须冻结角度正方向、`theta_zero`、编码器安装偏置和阵列正前方。装配偏心、传动回程和时间戳延迟要分别测量，不能统称为“编码器误差”。

## 6. 电源指标

| 电源对象 | 要求 |
|---|---|
| ZYNQ 开发板 | 使用原装或已验证的独立适配器 |
| 麦克风 | 使用安静的 3.3 V 电源；总电流留 2 倍以上裕量 |
| 电机 | 使用独立电机电源，不从开发板 3.3 V/5 V 扩展口取电 |
| 电机电源容量 | 连续电流 ≥驱动器设定电流需求的 1.5 倍，启动时不掉压 |
| 接地 | 信号地必须共地，但电机大电流回路与麦克风地在电源入口附近单点汇合 |
| 驱动端储能 | 驱动器附近放置符合其手册要求的电解/固态电容和 0.1 µF 高频去耦 |
| 保护 | 电机电源开关、保险丝或自恢复保险、反接保护和急停/使能 |

电机线与麦克风时钟/数据线分开走线；电机线尽量绞合。最终验收按第 5.6 节的五种状态保存原始证据，不能只依据主观听感判断“静音驱动”。

## 7. 音频输出与扬声器指标

现有 DAC 和领航者底板可能已经具备音频输出能力，因此本项暂缓购买，先核对实际硬件。

若需要外购：

| 项目 | 最低要求 | 推荐目标 |
|---|---:|---:|
| DAC 输入 | 48 kHz、16 bit | 48 kHz、24 bit、I²S/PCM |
| 通道 | 1 路 | 2 路，实际使用单声道也可 |
| 功放 | 能驱动实际扬声器 | 3～5 W，THD+N <1% |
| 扬声器 | 4 Ω 或 8 Ω，与功放匹配 | 3～5 W 全频单元 |
| 调试输出 | 耳机或线路输出 | 先用耳机/有源音箱验证，减少声反馈 |

最终扬声器不能靠近麦克风阵列，否则系统会把自身输出当作声源。扬声器播放与定位同时工作时，还要增加回声处理或时分工作策略；这不是第一阶段采购重点。

## 9. 明确不应购买的器件

- 只输出高低电平的“声音检测模块”；
- 带不可关闭 AGC 的麦克风模块；
- 四个独立 USB 麦克风或内部同步机制不公开的 USB 麦克风阵列；
- 只因为采样率高就购买的单通道 ADC；
- 直接输出 5 V 逻辑、又没有可靠电平转换的模块；
- 用于最终转台但没有位置反馈、回程间隙明显的廉价舵机；
- M0 阶段的显示屏、无线模块、滑环和装饰性结构件。

| 有界自测 | 安全 loopback 路由、输入模式、最小/典型/最大及非二次幂长度、超时、golden 规则 | 只能先设计，不能标记 hardware |
| 验收阈值 | 吞吐、延迟、重复次数、WNS、资源上限、错误/丢样阈值及各证据来源 | 待实现预算和实测基线后冻结 |
| 项目 payload 引用 | 独立 schema 的哈希/版本，描述四通道顺序、采样格式、ID、时间戳和错误元数据 | 不写入通用 DMA 合同，待 SoundSight 接口冻结 |
| 板上证据 | 实际观察到的板卡、Overlay 下载状态、身份读数、DMA 状态、缓存操作、耗时、首个错误和原始日志哈希 | 尚未取得 |

### 12.2 必须覆盖的真实故障与验收输入

| 输入或故障 | 必须保存的观测 | 判定边界 |
|---|---|---|
| 镜像与板级 DDR/MIO 不兼容 | 启动串口日志、设备树、内核和失败阶段 | 不进入 Overlay 下载；切换镜像/BSP 或后端 |
| `.bit`、`.hwh`、manifest 不同构建 | 三者哈希、build/interface/device/Vivado 信息 | fail closed，不按文件名猜测配对 |
| Overlay 缺少预期 IP 或身份寄存器不匹配 | `ip_dict`、地址、原始寄存器读数 | 写控制寄存器前停止 |
| S2MM 超时或缺少 TLAST | MM2S/S2MM 状态、TVALID/TREADY/TLAST 波形、传输长度 | 到期即停止并先抓状态，不自动全局复位 |
| CPU 或硬件看到旧数据 | TX/RX 缓冲地址、填充值与哈希、实际 flush/invalidate 记录 | 修正缓存所有权后重测，不能只重跑 Notebook |
| 长度、beat、对齐或最大块长错误 | 请求/实际字节数、流宽、对齐和首个截断位置 | 不静默取整；修正 profile 或设计 |
| 小块通过、长录音失败 | `sample_id`、每块耗时、环形缓冲/FIFO/丢样计数 | loopback 不能替代真实采集长稳测试 |
| SD/网络导出跟不上 | DDR 占用、写入/吞吐分布、丢块和停止原因 | 不反压采集；中止录音或明确标记缺失区间 |
| Notebook 显示正常 | 原始 evidence JSON、寄存器/DMA记录、构建与录音哈希 | 只能证明界面现象，不能判定系统路径通过 |

当前 profile 最强只能标记为 draft/offline 输入；完整 part、PYNQ 镜像、DDR/CMA、Overlay、DMA、自测和真实外设路径未证实时，不得生成“hardware passed”结论。
