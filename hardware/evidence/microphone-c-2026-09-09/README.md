## 模块接口标注及电气边界

以下编号仅抄录 C 提供的接口标注图，应以该图的朝向定位，**不是芯片封装脚号，也不是已完成通断测量的接线表**。

| 模块图编号 | 图中标注 |
|---|---|
| 1 | 3.3V 电源 |
| 2 | GND 地 |
| 3 | NC 空接 |
| 4 | L/R 声道选择 |
| 5 | CLOCK 时钟 |

手册第 7 页 Table 5 的 **1.62–3.6 V 是芯片 VDD 供电范围**，不能概括为模块接口“电平”。输入高低电平门限与 VDD 有关；不能据此认定整个转接模块支持任意该范围供电。模块图标注 3.3 V，仍需核实实际电路是否有稳压或电平转换。

手册第 11 页 Table 9 的裸芯片脚号为：1 DATA、2 VDD、3 CLOCK、4 LR、5 GND。不要与上表六针模块编号互换。CLOCK 输入和 LR 状态决定 PDM 输出时序；数据驱动边沿也不能直接当作 FPGA 采样边沿，后续须按时序窗口确定。
