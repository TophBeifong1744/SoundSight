# 四路采样时序与相位检查 — 2026-11-01

按run-fpga-workflow的ANALYZE范围只读核查，未改产品RTL/固件、未运行ILA、未重建或烧录。检查的是随原C交接包交付的S2源文件，快照在timing-reference，逐文件指纹在timing-reference-manifest.json。录音result.json中的S2 bit/hwh标识与既有基线相符，但没有本轮JTAG读回、实际IO波形或重新实施的时序报告，因此不是硬件全链路签核。

## 代码路径：未发现单通道独立错一个PCM采样点

1. `ss_pdm_capture.sv`：四路PDM共用phase；四个PDM时钟寄存器由同一个相位表达式更新。四个pdm_cic3共用clk/rst_n以及bit_valid=(phase==9)。数据同步器均为两级。pv四路必须同时有效，否则channel_fault。
2. `pdm_cic3.v`：每64次bit_valid抽取一次；四实例参数、复位及抽取计数一致，未发现按通道区别处理的移位/延迟。
3. `ss_clean_compute.sv`与`ss_pcm_time_cdc.sv`：四路S24合成96位，并作为同一个FIFO载荷跨域。每512样本的时间token虽会将整组载荷暂存一拍，但没有分别暂存某一路。
4. `ss_pcm_windows.sv`：每条RAM记录是一组96位四通道PCM，读窗的base/index共享。
5. `ss_preprocess.sv`：先复制完整1024组PCM到私有RAM，再按通道依次处理同一批index0..1023。后算的通道没有因此读取后来的现场音频。
6. `ss_fft_frontend.sv`：串行执行8个domain/channel单元，DOA采用domain1，所有通道处理自己的同窗PCM*Hann。不存在“依次FFT，所以声学样本依次延后”的关系。
7. `ss_audio_capture.sv`：输出交错S32时，四个通道读完才弹出一个96位PCM。原包/WAV逐样本核对结果也已通过。

按包装参数，采集时钟61.44MHz，PDM周期20拍即3.072MHz，CIC抽取64即48kHz。一个PCM点约20.833us；一个PDM周期约0.326us，半周期约0.163us。PDM边沿小量差异与1–2个PCM采样点不是相同尺度。这只是设计算术；未用它证明现场时钟、LR或数据眼图满足要求。

历史电路设计记载IM73D122V01、四路独立CLK/DATA及LR接地。现场实物接线与麦克风内部响应仍不能仅靠代码排除。

## 数据检查：单一固定延迟不足以解释全部相位变化

使用本人epoch37的593个高音量窗，计算平均跨谱和幅度平方相干度MSC。限定MSC>=0.8，带内功率不低于最大值的1/2500，至少8个频点。分别在328–984Hz、1031–1969Hz、2016–3984Hz上拟合：

`相位(f) = 常数相位 - 2*pi*f*delay/48000`

使用圆周残差搜索delay[-16,16]、步长0.01采样点，避免跨低相干频点做相位展开产生虚假2*pi分支。带内拟合有自由常数相位。结果是“相位斜率等效时差”，不是实际传播时差、不是板端lag、不可写入补偿配置。频率响应和多径会改变这个斜率；边界命中与残差大的拟合不得采信为真实延迟。

代表性CH1–CH2结果：

|时段|低频等效时差|中频等效时差|高频等效时差|
|---|---:|---:|---:|
|全段|+4.62|-6.27|+1.18|

全段低/中/高拟合残差RMS分别约0.047/0.125/0.321rad。两个半段也分别保存以检查频段变化是否只出现在一个短时片段。上述频段斜率明显不同，与“整个通道只是固定错开一个时间量”的简化模型不符，但不能排除较小固定延迟与声学/频响失真同时存在。

其他对也有明显频率相关变化，有的搜索触边。没有将超出物理界限的拟合数值解释为真实声程。声音本身存在时变性、相干估计有限，MSC高也不意味着只有直达声。此检查支持进一步区分声学/频响与固定偏移，不足以断言某只麦克风损坏或某条反射路径已被确认。

脚本check_phase_delay.py；phase-delay-analysis.json记录模型与全部结果。一个已知2.25采样点的纯延迟合成相位检查恢复正确值；带已知回声的合成相位会触发明显拟合残差。这是分析方法检查，不是RTL仿真或麦克风实测。

## 当前结论与下一次有效实验

没有找到可直接修复的单通道错拍代码证据，不能据此制造补丁。保留40mm几何，不写入从单方位录音拟合出的补偿值。

下一次采用同一手机、同一段宽带声音、相同距离/高度/音量，阵列绕自身中心水平旋转180度前后各录一次。理想情况下声源方向导致的水平时差应翻转，固定通道时间偏移不随同翻转。两个朝向能增加区分信息；真实反射/遮挡也会随阵列朝向改变，因此不能只凭“平均值非零”就宣判电子延迟。需要比较多频段一致性、几何预测和重复性。

该实验比再次在同一位置重复人声更有诊断价值。具体步骤及固定波形见CONTROLLED-TEST.md。尚未执行，先不发算法安装包。
